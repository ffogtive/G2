# 숨 주머니 + 멈춤점 — 설계 패널 최종 규격 (3차, 2026-10-12)

> 디자이너 4명(몸·감각 / 자·학습 / 시간·박자 / 경제·심리) → 심사 3명(말 없는 직관 / 실력·감·공정 / 구현 위험) → 종합. 심사 3명 모두 A안 1위 (A 8·7·8, D 6·5·6, B 5·4·4, C 4·3.5·3).
> 구현 메모: 아래 규격 대부분을 목업에 넣었다. 빠진 것은 `docs/design/round3-breath.md` 의 "아직 안 한 것" 참고.

**가설**: 숨 주머니는 볼의 고정된 용량 '꽉'(F=1.12)이다. 이 값은 지금 있는 모든 판의 정답보다 위에 있다. 꽉에 닿는 순간 숨이 더 안 들어가는 것(들숨 소리 끊김, 손끝 디텐트, 숨 줄기 정지)을 멈춤점으로 쓴다. 정답은 언제나 꽉 아래, 장수에 비례한 자리에 있으니 감이 실력으로 남는다. (미검증) → 16~40번째 숨에서 아래 셋 중 하나라도 나오면 틀린 가설이다: 꽉 ±5%에서 놓는 비율 10% 이상, ρ(장수, 놓은 파워) 0.5 미만, 무음 5초 클립에서 멈춤 프레임 적중 80% 미만(또는 꽉을 '성공'으로 읽는 비율 20% 이상).

## 2. 규칙 (rules.js에 순수 함수만 추가. resolveShot·sweetHiFor·물리는 안 바뀐다)

**상수**
- `POUCH_FULL` F = 1.12. sweetHiFor의 상한과 같다. 콘텐츠는 N ≤ 24라 hi ≤ 1.00이다.
- `POUCH_MAX` M = POWER_MAX = 1.25
- `POUCH_DETENT` 0.08u, `POUCH_GAIN` 0.4
- `STRAIN_MS` 1400(F에서) → 700(M에서), `STRAIN_RECOVER_MS` 900, `LEAK_AT` 0.35

**드래그 → 파워**
- u = max(0, dy) / (minDim·feel.pull)
- p = u (u ≤ F일 때) | F (F < u ≤ F + 0.08일 때) | min(M, F + (u − F − 0.08)·0.4)
- 390pt 폰, pull 0.42(1u = 164px) 기준: 꽉 183px, 디텐트 끝 197px, 벽 250px(지금 POWER_MAX는 205px)
- 꽉 아래는 지금과 1:1이라 정답 드래그 거리는 그대로다.

**마이크(로컬 전용)**
- p = min(M, 실시간 세기). 발사는 기존처럼 최고값으로 한다.
- 같은 링을 쓴다. F를 넘으면 링이 빨갛게 번쩍인다(히스테리시스 F−0.03).
- 버팀·콜록은 없다.

| n | hi | 초록 파워 | 꽉 대비 | 드래그 px | 꽉에서 비율 | 꽉에서 놓으면(실측, 조준 0.9, 시드 4) |
|---|---|---|---|---|---|---|
| 3 | 0.612 | 0.478–0.612 | 43–55% | 78–100 | 1.83 | 0장, 3장 OUT |
| 6 | 0.706 | 0.551–0.706 | 49–63% | 90–116 | 1.59 | 0장, 5.3장 OUT |
| 12 | 0.830 | 0.648–0.830 | 58–74% | 106–136 | 1.35 | 0장, 7.5장 OUT |
| 20 | 0.950 | 0.741–0.950 | 66–85% | 121–156 | 1.18 | 3.0장(초록 6.3장), 4.5장 OUT |
| 24 | 1.000 | 0.780–1.000 | 70–89% | 128–164 | 1.12 | 약 −25% 추정(비율 1.1 곡선 기준, 미실측) |

**꽉 도달**
- 켜짐: p ≥ F − 0.005. 꺼짐: p < F − 0.03 (래치).
- 들숨 소리가 끊기고 둔탁한 '읍', 25ms 진동.
- 볼이 링에 눌려 납작해지고 숨 줄기 입자가 멈춘다. 엄지 눈금이 실선으로 바뀐다.

**버팀 s (0~1)**
- 래치가 켜진 동안: s += dt / lerp(1400, 700, (p − F)/(M − F)). 꽉에 머물면 1.4초, 벽이면 0.7초 뒤 콜록.
- 래치가 꺼지면: s −= dt / 900. 0.2초 살짝 넘었다 돌아오는 건 아무 일도 없다.
- 신호 단계:

| s | 일어나는 일 |
|---|---|
| 0~0.35 | 얼굴이 붉어지고 떨린다 |
| 0.35 이상 | 입가로 'pff' 샌다(간격 260 → 140ms, 연출뿐이고 파워는 그대로). 땀 |
| 1.0 | 콜록 |

**꽉 너머에서 놓기**
- 보통 숨이다. ratio = p/hi로 기존 돌풍 경로를 탄다. n ≤ 24면 비율은 언제나 1.12 이상이다.

**콜록 (기본 `feel.coughCost=0`)**
- 강제 취소: 주머니가 0이 되고 제스처가 끝난다. 떼고 다시 눌러야 한다.
- 숨·턴을 쓰지 않는다. tutorialPuffs는 늘지 않고 profile.coughs만 +1.
- `coughCost=1`(재윤님 A/B용): fire({...aiming, power: hi·0.35, cough: true}). 비율 0.35 < WEAK_ZERO라 WEAK_FLOOR '들썩'만, 약 0장, 숨 1번 소모.

**꽉 아래에서 들고 있기**
- 시간 제한 없음, 벌 없음.
- PvP에는 파워를 바꾸지 않는 보이는 슛클록 10초를 둔다(P1).

**불변식**
- levelbot 시작 때 assert: 모든 판 N ≤ 24, sweetHiFor(N)·1.1 ≤ F.
- 산더미(n ≥ 30, hi가 F에 닿음)는 보스·이벤트 판 전용.

## 4. 코드 계획 (순서대로)
1. **rules.js**
   - 위 상수를 추가한다.
   - `pouchPower(u)`, `strainStep(s, p, dtMs, full)`, `fullLatch(p, was)`를 추가한다.
   - resolveShot과 sweetHiFor는 건드리지 않는다.
2. **main.js showGizmo:443**
   - `breath.p = power / sweetHiFor(n)`를 `power / Rules.POUCH_FULL`(절대값)로 바꾼다.
   - 이유: 지금은 충전 중 숨 줄기의 폭·alpha·입자 속도가 비율 1.0에서 포화해서, 숨겨진 정답 게이지가 된다.
   - blow():1329의 비율은 결과 연출에만 그대로 쓴다.
3. **main.js drawPuffer**
   - :550 `over = p > sweetHiFor(..)*1.12`를 지우고 heat = (who==='me' ? puffer.strain : 0)으로 바꾼다.
   - :571–580 볼 반짝이 3단(0.55/0.75/0.95, 금색 0.95 = hi(20))을 지운다.
   - 볼 반지름 = sqrt(0.06² + (0.161² − 0.06²)·min(p,F)/F). 지난 숨 고스트도 같은 함수를 쓴다.
   - `drawPouchRing(ctx, p, {full, strain, who, stage})`를 추가한다. drawBlowFace에도 같은 링 함수를 쓰고, charge 모드의 p는 절대값(0~M)으로 넘긴다. face-a 헤더의 '정답 대비'는 고친다.
   - mode 'cough'를 추가한다.
   - 아크 게이지(612~)에 ang(F) 노치와 F~M 빗금을 더한다.
4. **main.js playerShot**
   - move: aiming.power = Rules.pouchPower(u).
   - 래치가 켜질 때: sfx.cork(), vibrate?.(25), inhale.hold(), puffer.full = breath.full = true. 꺼질 때 inhale.resume().
   - 음계: guideStage() ≤ 1이고 p < F일 때만, step = min(7, floor(p/F·8)).
   - breath.press = {x: sx, y: sy}, breath.finger를 저장한다.
   - down: rAF 루프를 시작한다(dt ≤ 50ms). strainStep 결과를 puffer.strain / breath.strain에 넣고, 새는 소리 주기를 처리하고, s ≥ 1이면 cough().
   - cough(): coughCost 분기. 기본은 aiming = null, hideGizmo, inhale.stop, puffer.mode = 'cough'(700ms), breathFeedback('fbCough'). Promise는 그대로 둔다.
   - finish / cancel / pointercancel / visibilitychange(hidden) / blur: 루프를 멈추고 strain = 0, 숨을 쓰지 않고 취소한다.
   - up은 aiming이 null이면 무시한다. 콜록 뒤 늦게 오는 pointerup이 두 번 발사되지 않게 하기 위해서다.
5. **main.js drawBreath**
   - charge에서 breath.full이면 입자가 입 앞에 쌓여 멈춘다.
   - strain > 0이면 빨강 틴트 + 지그재그 ∝ s.
   - 엄지 눈금과 용수철을 그린다.
   - 꽉 너머 동안 500ms마다 chalkPulse().
6. **main.js breathFeedback**: 'fbCough'를 직접 호출하는 경로를 추가한다. stage 3이면 소리만.
7. **main.js aiShot**
   - 트윈은 그대로(≤ POWER_MAX), puffer.strain = 0.
   - 링은 guideStage() ≤ 1일 때만 그린다.
8. **audio.js**
   - cork(): 사인 260 → 140Hz 70ms + 짧은 클릭
   - leak(): 밴드패스 노이즈 80ms
   - cough(): 로우패스 노이즈 120ms × 2, 180ms 간격
   - inhale()에 hold()/resume() 추가
9. **i18n.js**: fbCough — ko '콜록! 너무 오래 참았어' / en 'Cough! Held it too long'.
10. **index.html**: `.breath-fb.fbCough{color:#ffb3b3}`. prefers-reduced-motion에서는 떨림을 1/3로.
11. **TUNE_RANGE**: strainMs [800, 2400, 50], coughCost [0, 1, 1]. F는 상수로 고정한다.

## 5. 플레이테스트 체크
1. **누설 0 자동 검사**: stage 3에서 같은 p(0.5 / 0.8 / 1.0)로 n=3과 n=20의 충전 화면을 그린다. #puffCanvas·#breath 해시가 같아야 한다. 다르면 정답 기준 신호가 남아 있는 것이다.
2. **무음·무진동 5초 클립**(꽉 도달 포함), 10명: 멈춤 프레임 적중 80% 이상, '좋은 순간'으로 읽는 비율 20% 미만.
3. **텔레메트리**(16~40번째 숨):
   - 꽉 ±5%에서 놓기 10% 미만
   - ρ(n, p) 0.5 이상
   - 콜록률이 충전의 5% 미만
   - 목발 지표(F·고스트 ±0.03에서 놓는 비율)가 세션마다 줄어든다
4. **엄지 가림**: 360·390pt 폰, 오른손·왼손 엄지로 '디텐트 끝을 넘긴 비율'(꽉을 놓침)을 잰다.
5. **스크린샷**: 4컷(반쯤 n3·n20, 꽉, 버팀 + 빨간 분필 원, 콜록) × stage 0과 3.
6. **타이밍**:
   - 꽉에 멈춰 있으면 1.4초 ± 50ms에 콜록한다.
   - 탭을 백그라운드로 보냈다 돌아오면 콜록하지 않고 취소된다.
   - 콜록 뒤 pointerup으로 이중 발사가 없다.
7. **봇**: pouchLearner와 learner의 L1~100 판별 클리어율 차이가 3%p 이하.

## 6. 재윤님 결정 필요
1. 콜록이 숨을 먹는가? 기본은 '아니오'(강제 취소). `coughCost` 토글로 직접 비교할 수 있다.
2. '무한으로 못 모은다'가 용량만인가, 시간도인가? 기본은 꽉 아래 무제한이고 PvP에만 슛클록을 둔다. 시간 제한도 원하면 꽉 아래에 연출만 있는 '피로'를 더한다.
3. 반짝이와 상대 기준 빨간 얼굴을 지우면 기존 테스터의 정확도가 잠깐 떨어진다. 둘 다 정답 누설이라 의도한 하락이다.
