# 재윤님 피드백·결정 기록 (1~10차)

## 🧭 핵심 가설

- **피드백은 매번 '화면과 손이 실제 경험처럼 이어지는가'로 모였다.** (확인됨, 1~10차를 묶어 본 결과)
  - 인과가 보이는가: 왜 넘어갔는지.
  - 숨을 실제로 쉬는 느낌이 나는가: 볼, 소리, 박동.
  - 실제 기술이 통하는가: 높이, 좌우, 입 높이, 숨 길이.
- 그래서 다음 설계(v2)의 판가름 기준은 '실제 딱지 불기에서 통하던 인과가 게임에서도 통하는가'다. (미검증)

## 지켜 온 원칙

- **가설 먼저.** 틀리면 '가설 수정'이라고 밝힌다.
- **플레이어 물리는 몰래 보정하지 않는다.**
- **정답이 하나로 쏠리지 않게 한다.** 센 선택에는 실제 대가를 둔다.
- **'내기·bet'이라는 말은 쓰지 않는다.** 판돈은 'POT'으로 쓴다(스토어 빌드에서는 대체어). 따먹기는 친구방 플래그로만 열고, 기본은 끈다.
- **유료 생성 크레딧은 승인을 받고 쓴다.** 토큰과 키는 채팅에 붙여 넣지 않는다.
