# PUFF! 물리·게임 설계서 v2 (앱 개발용)

- 작성: 2026-10-13. 재윤님 10차 피드백, 리서치 4건(물리·기술·게임 설계·코드), 설계안 3건(물리 v2·조작·시스템), 리뷰 4건을 합쳤다.
- 이 문서가 기준이다. 물리 v2·조작·시스템 설계안이 이 문서와 다르면 이 문서를 따른다.
- 리뷰 4건의 필수 수정 49개를 모두 반영했다. 그대로 따르지 않은 항목은 부록 A에 이유를 적었다.

## 🧭 핵심 가설

- **(확인됨)** 지금 더미가 눌린 원인은 무른 접촉(erp 0.2)이다. 눌림 정도는 약 n²·g/(2ω²)이다.
  - 정직한 접촉(300 Hz, ζ 10, 서브스텝 12, μ 0.45/0.38)으로 바꾸면 Rust rapier 0.36에서 64장이 높이 98.3%, 80장이 97.9%로 선다(리뷰 실측, 두께 0.048 u).
  - → 더미를 40~60장으로 키울 수 있다.
- **(미검증)** 몇 장이 넘어가는지는 숨 세기 숫자 하나로 정해지지 않는다. '내 쪽으로 열린 틈(쐐기)'에 들어간 제트 압력이 그 위 덩어리의 무게 모멘트를 이기느냐로 정해진다.
  - 세 자세와 두 숨은 입의 실제 위치와 숨의 시간 모양만 바꾼다. 손익은 물리에서 저절로 나와야 한다.
  - → 3D 스파이크(§7.2)로 판가름한다.
- **(미검증, 1번 위험)** '푸어억 + 고개 쓸기'의 진가가 정직한 물리에서 나오지 않을 수 있다. 2D 토이에서 쓸기의 평균 이득은 0이었다.
  - → S3 게이트를 통과하기 전에는 쓸기를 가르치지 않는다. 가짜 보너스는 넣지 않는다.
- **(미검증)** 더미 확대(피드백 ②)와 푸어억(피드백 ③)은 한 문제다.
  - 통일 비용으로 다시 돌린 장난감 DP 결과, 40장 이상에서는 한 판 안에서 정답이 바뀐다. 최대 퍽 → 중간 푸어억 → 퍽 순서다.
  - 섞어 쓰면 가장 좋은 단일 전략보다 +4~8%다(§6.3).
- **(확인됨)** 설계안 세 건은 손동작, 체력, 시간축에서 서로 달랐다.
  - → 이 문서가 하나로 정한다. 화면 초 = 시뮬 초 = 입력 초다. 숨, 체력, 고개 운동학은 Rust 한 곳에서만 계산한다.

> **읽는 법**
> - (확인됨) = 실측, 코드 확인, 또는 출처 2개 이상의 요약이 일치한 것. 원문 대부분은 프록시 정책 때문에 직접 열지 못했다.
> - (미검증) = 추정.
> - (규칙) = 물리가 아니라 게임 규칙이라고 밝힌 것.
> - 시간은 따로 적지 않으면 **화면 초**다. 실물 초 = 화면 초 ÷ 3.21. 길이 1 u = 25 mm = 딱지 반지름 R.

- **아바타 숨 상수 K_breath**: 최대 유량 3.9 L/s, 입 1.1 cm² → 35 m/s, 운동량 플럭스 J = ρU²A = 0.165 N = **딱지 무게의 14배**. Geoghegan 분포의 상위 약 10%에 둔 값이다(분위는 미검증). 게이트를 재기 전에 고정한다(§4.4).

### 2.3 제트

- **자유 원형 제트**: 중심 속도 Uc = U₀·min(1, B·d₀/x), B = 5.8 [H94]. 속도 반폭 r½ ≈ 0.1015·x(퍼짐 0.094~0.10).
- **운동량 플럭스 J는 거리와 무관하게 보존된다.** 포텐셜 코어는 입 지름의 4~7배다 [core].
- **입 바람은 딱지 한 장을 고를 수 없다.** 8 cm 거리의 반값 폭은 약 15 mm, 곧 ±6장이다. 조준은 '점'이 아니라 '띠'다.
- **충돌 제트**: 막힌 큰 면이 받는 총력 ≈ J·sinθ, 정체점 Cp ≈ 1 [BR]. 벽면 제트는 옆으로 수직의 약 5배 빨리 퍼진다 [WJ].
- **코안다**: 모서리 반경이 제트 두께보다 커야 붙는다 [NASA]. 교실 책상 모서리(약 2 mm)는 떨어지는 쪽이다.
- **와류 고리**: 행정길이/직경 ≈ 4를 넘으면 고리 뒤에 줄기가 붙는다 [Gh98]. 퍽은 약 200이라 준정상 제트로 다뤄도 된다.

### 2.6 비행·뒤집힘

- 깔끔한 뒤집힘: 테두리 축 회전 약 25 rad/s(실물), 높이 2 cm, 0.13 s.
- 35 rad/s에서는 반 바퀴를 두 번 돌아 **도로 엎어진다**. 50 rad/s는 동전 던지기다 [DHM].
- 종이 원판은 흔들리고 텀블한다 [F97]. 그래서 과한 숨의 손해는 가짜 난수 없이 홀짝에서 나온다.

## 3. 실제 기술 지도: 앵글 3 × 숨 2 × 고개 쓸기

결과 칸은 성인 아바타(K_breath 14) 기준 리서치 추정이다(미검증). 띠는 3D 스파이크와 아틀라스 결과로 다시 정한다.

### 3.1 지도

| 자세 × 숨 | 입과 제트 | 물리 원인 | 예상 결과 | 진짜 대가 | 맞는 때 | 게이트 |
|---|---|---|---|---|---|---|

### 4.3 휨과 틈

| 종류 | 비율 | 테두리 들림 δ(φ) | 만드는 틈 |
|---|---|---|---|
| 평평 | 30% | 0 (a = 0) | 거칠기만 |
| 굽음 | 35% | a·sin²(φ−ψ) | 마주 보는 두 가장자리 |
| 말림 | 25% | a·max(0, cos(φ−ψ))³ | **한쪽만 열린 쐐기**. 입 쪽이면 최고 효율 |
| 오목 | 10% | a | 둘레 전체(옆으로 샘) |

- **크기 a**: 로그정규 분포, 중앙값 0.020 u(0.5 mm), p90 0.045, 상한 0.064. 실측 R2 전에는 (미검증).
- **틈 (위 장 i, 받침 s, 테두리 표본 24개)**: g_k = g_rb,k + δ_i(φ_k) + (a_s − δ_s(φ_k)) + g₀
  - g₀ = 0.002 u.
  - g_rb는 강체 자세에서 잰 벌어짐이다.
  - (a_s − δ_s)는 받침 딱지 두께 안의 빈 공간이다. 말린 받침이 위 장을 한쪽에서 받치면 반대쪽에 틈이 생긴다. 실물과 같은 인과다.
  - 책상은 a = δ = 0이다.
- **안쪽 틈장**: h(r, φ) = g₀ + (g(φ) − g₀)·(r/R)².
- **틈 입구의 보임 판정**: 충돌체가 아니라 휨을 반영한 가상 기하로 한다. 충돌체끼리는 맞닿아 있어 광선으로 보면 입구가 늘 가려진다.
- **렌더**: 메시를 δ·(r/R)²만큼 굽힌다. 휨은 두께 안에 있으므로 이웃 딱지를 파고들지 않는다. 열린 틈은 별도 그림자 선으로 그린다(§5.7). 공력용 a와 렌더 과장은 분리한다.
- **레벨·아이템 손잡이** (모두 물리량):
  - 휨 배율 0.5~1.5, 종류 비율, σ_s
  - 눌린 더미 = a × 0
  - 휜 더미(휴식판) = 말림 비율 ↑

### 4.4 숨 모델: 원시 입력 → BreathProgram (Rust `breath.rs`, 유일한 구현)

```
입력 기록(권위, 시뮬 스텝마다 30 Hz ZOH 양자화):
  pose(2b) · armed(1b) · aim(lat, h) · [pull q12, sweep s q8(부호), flags(start/stop)]  // 2 s 누름 ≈ 180 B
Rust가 결정적으로 만든다:
  q(t)   = min(1, p_eff/F),  p_eff = pouchPower(u)·(1+박동),  F = 1.12 (꽉)
  Q(t)   = Q_max·q·envelope(t),  Q_max = 3.9 L/s  (K_breath, 고정)
  A(t)   = 퍽 1.1 cm² / 푸어억 1.1 → 2.5 cm² (§4.1 시간표)
  j(t)   = ρ·Q²/(A·W)            // 퍽 꽉 = 14.2, 푸어억 꽉: 14.2 → 6.2
  M(t), d(t) = 자세 회전축 + 고개 각 φ(t) (목 속도·가속 상한) + 옆걸음 lat
  cost   = 2.0·V[L] + 4.5·((q_peak − 0.8)₊/0.2)²   // §6.1, (규칙)
```

- **꽉 너머**: 디텐트에서 벽까지 당겨도 세기는 같고 버팀만 빨리 닳는다. 꽉 = 아바타 최대 숨이다.
- **표준 폐**: 모든 아바타가 같다. 한 숨의 부피 상한은 매번 폐활량 3.0 L이고 체력과 무관하다. 꽉 푸어억도 상한 시간 안에 2.5 L라 넘지 않는다.
- **K_breath 고정 절차**:
  - 기본은 14(Geoghegan 상위 약 10%, 미검증)다.
  - 실물 보정 R3/R4를 하면 **한 번만** 바꿀 수 있다. 그 뒤 동결한다.
  - 게이트 띠가 안 맞으면 K가 아니라 띠(기획 목표)를 고친다.
- **Dart의 역할**: 입력을 양자화해 기록만 한다. v2에서는 `rules.dart`·`detmath` 숨 해석 경로를 쓰지 않는다.
- **서버의 역할**: '낼 수 있는 숨인지' 검증할 필요가 없다. 어떤 입력이든 합법이고, 프로그램은 입력에서 결정적으로 나온다.

- 카메라 = 눈 = 입 + (0, +2.6, +0.8) u (6.5 cm 위, 2 cm 뒤).

### 4.8 갱신 주기·성능

- **공력 갱신**
  - 제트가 켜진 동안 바깥 스텝은 1/480 s, 서브스텝 3이다. 가림·F4·벽면 제트를 매 바깥 스텝 다시 계산한다.
  - 제트가 꺼지면 1/120 s, 서브스텝 12다.
  - 수렴 게이트 G4: 공력 갱신을 240/480/960/1440 Hz로 바꿔 돌린다. 1440 Hz(서브스텝마다) 기준과 비교해 평균 뒤집힘 차 < 5%, P(0) 차 < 2%p인 가장 낮은 값을 쓴다.
- **가림**
  - 핫패스에서 parry `cast_ray`를 금지한다. 64장 표본 3200개 실측: parry 전수 46.6 ms, AABB 후 parry 14.4 ms, 해석적 전수 3.7 ms.
  - 모든 딱지를 해석적 '광선 vs 평평한 원기둥'으로 판정한다. 책상은 상자로 해석적으로 판정한다.
  - 광선을 쏘기 전에 버린다: 뒷면 표본(c ≤ 0), 가우스 꼬리(r > 3r½), 제트 축 구간 밖.
  - 옛 '40장 이하 전수 검사'와 '온전한 더미만 해석적' 모드 전환은 지운다. 모드가 바뀔 때 힘이 튄다.
  - 예산: 갱신 1회 ≤ 0.5 ms (x86, 64장).
- **결정적 꼬리 컷**: Π < Π_min이면 힘도 걸지 않고 깨우지도 않는다. 이게 없으면 64장 전부가 매 스텝 깨어 잠들기가 사라진다.
- **스레드**
  - 시뮬은 전용 Rust 스레드에서 돈다. 자세는 링버퍼로 넘긴다.
  - 퍽 결과는 다 계산한 뒤 재생하지 않고, 백그라운드에서 재생보다 앞서 계산해 흘려보낸다.
  - 푸어억은 밀기 시작부터 멈출 때까지 입력과 같은 박자로 스텝을 밟는다.
- **이벤트 내보내기**: 시뮬이 '수직 통과(뒤집힘)·착지·원 밖'을 스텝 번호와 함께 낸다. Flutter는 이것으로 햅틱과 소리를 예약한다.

- **자리**: 오른쪽 아래 56 × 176 pt. 위에서부터 눈높이 / 턱 / [나무 책상 줄] / 책상 밑. 책상 줄이 왼쪽으로 10 pt 튀어나와 아래 칸이 '책상 아래'로 읽힌다.
- **보이는 칸**
  - 쓸 수 있는 칸만 나온다. 죽은 회색 버튼은 두지 않는다.
  - 책상 밑 칸은 기하 조건(§4.5)이 맞을 때 레일 아래에서 미끄러져 들어온다.
  - 책상 끝 판에서는 턱 칸이 숨는다.
- **기본**: 매치를 시작하면 턱이다. 내 차례마다 고른 자세를 유지한다.
- **전환**
  - 카메라와 입이 350 ms 동안 옮겨 간다(임계감쇠). 그동안 누르기는 받지 않는다. 자세 소리와 `poseNotch` 햅틱이 함께 난다.
  - 모션 줄이기를 켜면 0.15 s 페이드다.
  - 책상 밑으로 갈 때는 0.3 s 동안 쪼그려 앉는 실루엣을 먼저 보이고, 책상 모서리 띠를 두껍게 그린다.
- **자이로로 고르지 않는다**: 이산 선택이고, Apple HIG가 플레이 밖 UI를 기울기로 조작하지 말라고 한다 [HIG-g]. 카메라가 기울기를 따라가면 멀미가 난다 [XAG].
- **화면이 보여 주는 것**
  - 눈높이: 윗면과 맨 위 말림.
  - 턱: 옆 틈(쐐기)이 잘 보인다. 큰 더미 윗면은 일부만 보인다.
  - 책상 밑: 화면 높이 58%를 나무 띠가 가로지르고, 그 위로 앞면과 돌출 밑면만 보인다. 위가 안 보이는 것이 이 자세의 대가다.

### 5.3 숨 풍선 (위젯 하나, 이름 하나)

- **이름**: '숨 풍선 / Breath Balloon'. 볼은 '볼(숨 주머니)'이다. 숨통, 가슴 풍선, 폐 게이지라는 이름은 쓰지 않는다.
- **자리**: 왼쪽 아래 64 × 80 pt, 10칸. L11 해금 뒤 **늘 보인다**. 가득 차도 접지 않는다(장착 스위치를 겸하기 때문).
- **장착**
  - 톡 하면 1.15배로 부풀고 꼬리 리본이 생긴다. 1인칭 입술이 'O'를 예고하고 `armLong` 햅틱이 울린다. 다시 톡 하면 해제된다.
  - 숨 1번 동안 유지된다. 콜록이나 취소면 장착이 유지된다.
- **비용 홈 (필수)**
  - 장착한 채 당기는 동안, 풍선 테두리에 '이번 숨 최대 비용'(이 당김으로 1.93 s 끝까지 불 때)만큼 점선 홈이 파인다.
  - 홈과 입 'O' 크기가 함께 커진다. 떼기 전에 '많이 들이쉬었다'가 읽힌다.
- **부는 동안**: 실시간으로 쪼그라든다. 회복할 때는 '흐읍' 소리와 함께 0.4 s 동안 부푼다.
- **헐떡**: 풍선이 축 처지고 땀방울이 맺힌다. 기침이나 질식 이미지는 쓰지 않는다.
- **공개 정보**: 상대 풍선도 상대 얼굴 옆에 작게 보인다.
- **넛지**: 40장 이상 판의 첫 숨 전에, 아직 장착하지 않은 플레이어에게 한 번 '통' 튄다. 정답이 아니라 버튼이 있다는 것만 알린다.

### 5.4 고개 쓸기

- **공통 신호**: s(t) ∈ [−0.2, 1]. 자세별 운동학은 §4.5다. 저역통과 10 Hz다.
- **엄지 (기본)**
  - 5 pt = 1°, 끝까지(24°) = 120 pt.
  - 이득은 자세·확대와 관계없이 고정이다. 근육 기억을 일정하게 하기 위해서다.
  - 아래로 쓸면 조준이 내려간다('연속 벗기기' 실험용, 미검증).
- **자이로 (선택, 기본 끔, L16 설정에서 해금)**
  - 부는 동안에만 읽는다(PUBG 'Scope On' 방식 [PUBG]). 0점은 밀기를 시작한 순간이다.
  - 폰 1° = 고개 1°, 데드존 2°, 100 Hz.
  - 엄지와 같은 s, 같은 상한이다. 둘 다 켜면 큰 값을 쓴다(더하지 않음).
  - 기록에는 s만 남는다. 원시 자이로에 권한 문구가 필요한지는 (미검증).
- **속도**: 좋은 쓸기는 턱 자세 기준 고개 6~13°/s(엄지 30~65 pt/s)이고 약 1~2 s짜리 '보며 따라 미는' 동작이다.
  - **가설 수정**: 조작안의 '0.3 s 탄도 동작' 전제는 실물 초였다. 화면 초로는 눈으로 따라갈 수 있다.
- **카메라**
  - 고개 움직임의 35%만 따라간다(피치 ≤ 5°, 상승 ≤ 0.3 u). 모션 줄이기를 켜면 0이다.
  - 장착하면 0.3 s 동안 숙여 더미 중심을 화면 위쪽 42%에 둔다. 엄지가 더미를 덜 가린다.
  - 부는 동안 세상은 느린 세계 그대로 1배속이다.
- **가르치기**
  - '푸—어억' 소리의 포먼트가 입 면적 A(t)와 같은 시계로 바뀐다(약 1.1 s). 소리 자체가 박자다.
  - 쏜 뒤 '방금 숨' 카드에 쓸기 그래프를 그린다. 실선은 바람 자국 높이, 점선은 실제로 들린 테두리(물리 기록)다. 거북·토끼·엄지척으로 판정한다.
  - **S3(B4) 통과 전에는 그래프와 아이콘을 끈다.**

- 숨 1번에 이벤트 12개 이하.

- **일레븐랩스 생성**: 푸어억 어택·루프·꼬리 각 4, 가슴 들숨 3, 헉 2, 자세 폴리 6, 풍선 2. **유료 크레딧은 재윤님 승인 뒤에 쓴다.**

### 5.6 물안경 신호 (파란 테 없음)

1. **없앤다**: 렌즈 테 2개와 하늘색 막. 화면을 덮는 것은 모두 없다.
2. **켜는 순간**
   - 칩이 물빛으로 차고 반짝인다. '찰칵·뽁' 소리와 `goggleOn` 햅틱이 난다.
   - **칩 아이콘이 더미로 날아가** 정보층 끝에 작은 물안경 기호로 붙는다. 그 숨 내내 보인다(0.5 s, 화면을 덮지 않음).
3. **정보층 자체를 물빛으로 그린다**: 물방울 가장자리를 쓴다.
4. **체험 끝(L3 시작)**: 할머니가 내 물안경을 벗겨 칩(×3)에 넣는 장면을 넣는다. '게임이 고장 났다'로 읽히지 않게 한다.
5. **3인칭**: 쏜 뒤 재생과 상대 화면에서는 내 아바타가 물안경을 쓰고 있다.
6. **색각**: 물결의 노랑·초록·빨강은 무늬로도 구분한다(점선 / 굵은 실선 / 지그재그).

### 5.7 화면에서 읽히게 (결과를 가르는 변수는 보여야 한다)

- **틈 그림자**
  - 열린 틈을 최소 3 pt 짙은 선이나 그림자로 그린다. 굵기는 실제 틈에 단조로 비례하고 위치는 정확해야 한다.
  - 휨은 폰에서 약 2 px라 그대로는 안 보인다. 같은 샷이 다른 결과를 내면 운으로 느껴진다.
- **테두리 색 띠**: 딱지 테두리에 색 띠를 번갈아 넣어 장수를 셀 수 있게 한다.
- **바람 자국**: 조준 띠를 가우스 타원으로 그린다(턱 약 15 mm, 눈높이 약 36 mm, 책상 밑 약 14 mm). 정답이 아니라 내 입이 만드는 바람의 실제 크기다.
- **실패 서명** (물리 결과로, 기본 켬)
  - 통째 미끄럼 = 책상 미끄럼 자국 + '쓱' (너무 셈)
  - 들썩 후 내려앉음 = 펄럭 (너무 약함)
  - 두 번 뒤집힘 = 빙글 자국 (과함)
  - → 글 없이 '작은 더미 = 살살'을 배운다.
- **목표 표시**: 가져온 딱지 더미 옆에 분필 목표 줄을 긋는다. 숫자는 작게 둔다.
- **위젯 수**: L1~20에서는 누르기 전에 보이는 위젯이 3개 이하다(레일·풍선·칩).
- **옆모습 창**: 튜토리얼에서만 더미 옆에 띄운다. 평소에는 '방금 숨' 카드에서 재생한다.

### 5.8 튜토리얼 (글 없음, 위젯을 하나씩 공개)

| 레슨 | 판 | 보기 | 따라 하기 | 성공 | 조건 |
|---|---|---|---|---|---|
| A 퍽 | **L1~2 턱, 8~10장**, 미리 고른 시드 | 손가락 시범. 당김은 **0.5F에서 멈춘다** | 누르기-당기기-놓기 | 처음 하는 사람의 **85% 이상이 첫 숨에 1장 이상** | — |
| B 눈높이 | L3, 8장, 맨 위가 입 쪽으로 말림 | 할머니가 위에서 '퍽' → 맨 위 1장 | 레일이 나타난다(눈높이·턱) | 맨 위 1장 | — |
| C 푸어억 | **L11, 40장 이상**. 바로 앞 L9 결투에서 라이벌 지우가 푸어억 시범 | 풍선 톡 → 길게 | 풍선 톡 → 더미 아래 1/3 → 당김 → 위로 밀기 → 떼기 | 덩어리 뒤집힘 | **S2(B2) 통과 시에만.** 실패하면 해금을 미룬다 |

- 첫 시도는 미리 고른 시드를 쓴다. 물리는 손대지 않는다.
- **효과 없는 기술을 시드로 효과 있는 것처럼 보이지 않는다.**
- 같은 레슨에서 2번 실패하면 조작 시범을 한 번 더 보여 준다(정답 누설이 아님).

### 5.9 접근성

| 필요 | 대안 |
|---|---|
| 길게 누르기·끌기가 어려움 [GAG] | 탭 모드: 퍽 = 탭(조준) → 볼 바늘(1.6 s 주기) → 탭. 푸어억 = 탭(세기) → 탭(시작) → 탭(멈춤). 쓸기 속도는 누르기 전에 거북 0.35 / 보통 0.55 / 토끼 0.8 u/s 중 고른다 |
| 탭 모드 공정성 | **랭크에서는 금지**(통일). 솔로 게이트: 탭 모드 결과 분포 ≤ 중간 엄지 분포. 넘으면 프리셋에 같은 σ의 결정적 흔들림을 넣는다 |
| 멀미 [XAG] | 모션 줄이기: 쓸기 카메라 0, 전환은 페이드, 흔들림 × 0 |
| 왼손잡이 | HUD 좌우 반전 |
| 무음 | 리본 굵기 = 세기, 입 모양 = 단계, 풍선 = 체력으로 끝까지 읽힌다 |
| 색각 | 실루엣, 크기, 무늬 |
| 저시력 | 옆모습 창 1.5배. 칸 56 pt, 풍선 64 pt 이상 |

### 5.10 마이크 모드 (REAL BLOW) 안전

- 세기는 개인 최대치로 1회 보정한 비율을 쓴다. 아이 PEF 약 260 L/min, 성인 350~600 L/min이라 보정 없이는 불공정하다.
- 긴 숨은 **2분에 6회까지**다. 넘으면 60 s 동안 마이크 긴 숨을 막고 풍선 '쉬는 중' 그림을 보인다. 13세 미만은 기본 켬이다.
- 랭크에서는 쓸 수 없다. 쓸기는 엄지나 자이로로 한다.

### 6.1 숨 풍선 (판 안 체력, 규칙은 Rust `breath.rs` 하나)

| 항목 | 값 | 근거·성격 |
|---|---|---|
| 최대·시작 | 10칸 | (규칙) |
| 비용 | **2.0·V[L] + 4.5·((q_peak − 0.8)₊/0.2)²**. 실제로 분 숨에서 정산 | (규칙). 이야기는 '큰 숨과 센 숨이 쌓이면 숨이 차다(과호흡, 미검증)'. 생리 근거라고 주장하지 않는다 |
| 회복 | 내 차례 시작마다 +3 (L11~15는 +4) | 결정론. 지연으로 이득 볼 수 없다 |
| **당김 상한** | 이번 숨의 최대 가능 비용(장착이면 1.93 s 끝까지)이 남은 칸을 넘지 않는 q까지. 그 지점이 **꽉**이 된다(당김이 짧아지고 풍선 홈에 보인다) | 숨을 몰래 약하게 하지 않는다. 최소 문턱에서 시작해 비싼 숨을 끝까지 부는 악용을 막는다 |

| 장착 최소 | 1.5칸 (가장 약한 푸어억의 최대 비용) | 모자라면 '헉' + `exhausted`로 거부 |
| 헐떡 | 숨 뒤에 1칸 미만이면 **다음 내 차례 푸어억 장착 불가. 이것 하나뿐이다** | 벌칙을 겹치지 않는다. 회복 감소, 조준 흔들림, 세기 감소는 없다 |

| 숨 | 공기 V | 비용(칸) |
|---|---|---|
| 퍽 q 0.5 / 0.7 / 0.85 | 0.17 / 0.23 / 0.28 L | 0.3 / 0.5 / 0.8 |
| 퍽 q 0.95 / **1.0 (최대)** | 0.31 / 0.33 L | 3.2 / **5.2** |
| 푸어억 q 0.8, 화면 1 s / 1.93 s | 1.1 / 2.0 L | 2.2 / 4.0 |

- **불변식**: 중간 퍽(q ≤ 0.85)만 쓰면 숨 풍선이 절대 막지 않는다(0.8 < 3).
- 아이와 어르신에게는 이것이 안전한 바닥이다. 다만 '깰 수 있음'은 보장하지 않는다. 그것은 보정 게이트(§7.6)가 맡는다.

### 6.3 통일 비용 장난감 DP (재실행, 근거가 아니라 방향 감)

- **조건**: 물리 토이 턱 표를 K 14로 다시 맞췄다. 작은 더미 미끄럼 손실 포함, 위 비용식, 회복 +3, 기대 장수 최대화.
- **한계**: 토이 위의 토이다. 2D 강체이고 오라클 조준이다.

| 판 | 중간·센 퍽만 | + 최대 퍽 | + 푸어억 | **전부** | 최적 순서 (남은 장수:선택) |

- **읽은 것**:
  - 섞어 쓰기가 가장 좋은 단일 계열보다 +4~8%다. 단일 정답은 없다.
  - 최대 퍽 비용을 2.0으로 낮추면 최대 퍽이 3~4번으로 늘어난다. 그래서 c_P 4.5를 기본으로 한다.

- **남은 장**: 다리나 판이 끝났을 때 남은 딱지는 무효다. 따먹기 모드에서는 원래 주인에게 돌아간다.
- **랭크 목표**
  - 섞어 쓰기 봇 대 퍽만 봇 승률 60~75%를 목표로 한다.
  - 아틀라스에서 40장일 때 섞어 쓰기 이득이 5% 미만이면 목표를 52~58%로 낮춘다. 그때는 '숨 풍선은 랭크의 실력 축이 아니다'라고 문서에 명시한다.
- **선공 이점**
  - 2다리 교대로 1차 상쇄한다.
  - 선공 승률이 55%를 넘으면 '선공 숨 풍선 5칸으로 시작' → 4칸 순으로 시험한다(4칸이면 센 푸어억 불가).
  - GDD §7.3의 왕복전 잔여 편향(2라운드 선공 +8~9%p, 가위바위보 승자 이점)을 같은 표에서 함께 잰다.
- **AI 라이벌**: 사람과 같은 입력 기록을 만든다. 실력은 ★로 공개한다. 판 중간 러버밴딩은 금지다. 버릇이 보여야 한다(풍선, 고개 들기).
  - 콩이(눈높이 퍽) / 민수(턱 퍽) / 지우(+ 푸어억) / 할머니(책상 밑) / 골목대장(+ 쓸기) / 딱지왕(숨 계획).
- **전송**
  - 입력만 복제하는 lockstep으로 간다. 턴마다 양자화한 원시 입력 약 100~400 B를 보내고 받는 쪽이 다시 시뮬한다.
  - 궤적은 대비책이다(30장 움직임 × 4 s ≈ 47 KB, 목표 20 KB 초과).
  - 서버 재시뮬은 표본 10%, 해시 불일치, 신고, 상위 랭크만 한다.

## 7. 합격 기준과 측정 도구

### 7.1 측정 원칙

1. **먼저 고정**: K_breath, 휨, μ를 R1~R3로 고정한다. 하지 못하면 §4.11 기본값으로 동결한다. 그 뒤에 게이트를 잰다.
2. **공통 난수(CRN)**: 비교하는 모든 팔에 같은 더미 시드를 쓴다. 짝지은 차이와 부트스트랩 2000회로 신뢰구간을 낸다.
3. **오라클 분리**: 오라클 조준은 시드 1~32로 고르고 33~64로 보고한다(선택 편향 +1.5 SE 제거).
4. **검정력**: 문턱은 검정력 계산으로 정한다(예: D3 ≥ 5%p). 시드 32개로 1%p를 가를 수는 없다.
5. **띠 위반 처리**: 범위 안 손잡이 → 기획 목표 → 실물 실험 순서로 고친다. 가짜 힘은 넣지 않는다.

### 7.2 3D 스파이크 go/no-go (S, 1주, 약 5천 샷, 4코어 30~40분)

- **구성**: 정직 접촉 원기둥 더미 + 벽 법칙 F1·F3·F4 + BreathProgram + F6(정지 공기)만. 벽면 제트, 감사, UI는 없다.
