# PUFF! GDD v0.2 개정분 — v0.1.1에 붙이는 변경

## 🧭 핵심 가설

- **G1 (미검증)**: 메인 진행을 '판돈 테이블 사다리'에서 **레벨 1~10,000**으로 옮긴다. 레벨은 하우스 판이라 내 딱지를 잃지 않는다. 이렇게 하면 '컴퓨터와 하는 게임'이라는 전제와 등급 안전을 함께 얻는다 → 판가름: 레벨 모드 유저의 D7이 테이블 모드보다 높고, IARC 드라이런에서 '시뮬레이션 도박'이 표기되지 않으면 확인(E16, E24).
- **G2 (미검증)**: 난이도는 세 가지로만 조절하고 숨은 보정은 쓰지 않는다.
  - 공개된 10판 톱니
  - L300 이후 고정되는 기준선
  - 눈에 보이는 도움

  → 판가름: 봇 예측 통과율과 실제 통과율의 상관 r ≥ 0.7, 'HARD 판 직후 이탈률'이 일반 판 직후의 1.5배 이하이면 확인(E23).
- **G3 (미검증)**: 정답 구간은 쌓인 양에 따라 움직이되, 4단계에 걸쳐 바래다가 사라진다. 그 뒤에는 절대 눈금과 지난 숨 흔적만 남긴다. 이것으로 감이 생긴다 → 판가름: 16~40번째 퍽에서 ρ(장수, 놓은 파워) ≥ 0.5(E17, E19).
- **G4 (미검증)**: 접촉 프레임과 실패 서명 5종만으로 '왜 넘어갔나'를 글 없이 설명할 수 있다 → 판가름: 무음 5초 클립을 보고 원인을 맞히는 비율 ≥ 70%(E18).
- **G5 (미검증)**: 수집을 '동물 크리처 종 × 6주 의상 시리즈 × 마감'으로 바꾼다. 그러면 시즌 신규 아트가 54장에서 10장으로 줄어도 1만 판 동안 새 칸이 마르지 않는다 → 판가름: E21 페이크도어에서 크리처가 1위이고, 하루 10판 기준으로 '15판당 새 목표 1개 이상'을 유지하면 확인.

## 레벨 & 진행 설계 (1~10,000)

### 1. 위치와 판 종류

- **레벨 모드는 메인 진행이다.** 모든 판이 '컴퓨터가 낸 판'이다. 결투판도, 라이벌이 차려 둔 도전판도 그렇다.
- **하우스 판이다.** 판의 딱지는 시스템이 깔고, 내 딱지를 걸지 않으며 잃지도 않는다. 목업은 이미 레벨 판을 'fun' 모드로 돌린다.

| 종류 | 내용 | 길이 | 비율(초안) |
|---|---|---|---|
| 도전판 `challenge` | 라이벌이 차린 더미를 K번 안에 공략 | 20~40초 | 약 78% |
| 결투판 `duel` | AI 라이벌과 번갈아 불기(원작 룰, 레벨 모드 판돈 = 시스템 지급) | 60~120초 | 약 20% (x4, x9) |
| 보스판 `boss` | 동네 골목대장(idx 49), 지역 딱지왕(200판마다) | 90~150초 | 동네당 1 |
| 동네 완성판 `finale` | idx 50. 쉬운 판 + 재건 완료 연출 + 상자 + 동네 액자 딱지 | 약 20초 | 동네당 1 |

### 2. 레벨 데이터 구조

현재 `levels.js levelSpec(n)`은 아래 필드를 결정론적으로 만든다.

```
n, tier, role, rate, chapter, chapterIdx, idx,
type(flip/golden/rival), N, heavy, intro, seed, k,
puffs, target, goldenDepth, rival, stake, aiSkill
```

v0.2에서는 이것을 **블루프린트(고정) + 재추첨 밴드 + 봇 리포트** 구조로 확장한다.

```json
{
  "n": 137,
  "region": "hometown", "chapter": "school", "idx": 37,
  "slot": 7, "role": "applied", "tier": "normal", "mark": null,
  "kind": "challenge",
  "blueprint": "twin_towers_eraser",
  "piles": [
    {"shape": "column", "n": 12, "at": [-1.4, 0]},
    {"shape": "steps",  "n": 8,  "at": [1.6, 0]}
  ],
  "house": [
    {"type": "golden", "depthBand": [0.3, 0.6]},
    {"type": "tape", "count": 2},
    {"type": "sealed", "count": 1}
  ],
  "props": [{"type": "eraser", "at": [0.2, 1.1], "rot": 30}],
  "env": {"floor": "desk", "tableR": 7, "fan": null, "restack": true},
  "goal": {"type": "flipN", "n": 11, "puffs": 3},
  "stars": {"2": {"puffsLeft": 1, "orFlip": 15}, "3": {"puffsLeft": 1, "andFlip": 15}},
  "rival": null,
  "intro": null,
  "reroll": ["stackOrder", "goldenDepth", "sealedFace"],
  "seed": 1938475,
  "target": {"userP": 0.74, "botP": null},
  "bot": {"runs": 300, "novice": 0.31, "learner": 0.52, "expert": 0.86,
          "skillGap": 0.55, "nearMiss": 0.47, "oob": 0.08, "secs": 28},
  "rewards": {"bricks": 1, "sealedPool": {"season": 0.5, "dex": 0.5}}
}
```

| 현재 필드 | v0.2 필드 | 메모 |
|---|---|---|
| `type: flip` | `goal.type: flipN` | 목표 4종 추가: `exact`(정확히 N장), `gold`, `color`, `cup` |
| `type: golden`, `goldenDepth` | `house[golden].depthBand` | 깊이를 한 값이 아니라 밴드로 두고 재시도 때 다시 뽑음 |
| `type: rival`, `stake`, `aiSkill` | `kind: duel`, `rival{id, stars}` | 라이벌 실력은 ★로 공개하고 고정 |
| `N` | `piles[].n` | 여러 탑 지원 |
| `heavy` | `house[tape].count` | 테이프 감은 무거운 딱지(밀도 ×3, `sim.js`에 있음) |
| `k`(난이도 손잡이) | `target.userP`, `bot` | 유저 목표와 봇 측정값을 분리 |
| `seed`(레벨마다 고정) | `seed` + `reroll` | 재시도 때마다 밴드 안에서만 다시 뽑음 |

### 3. 생성 규칙

1. **단위**: 10판 블록 두 개가 한 에피소드(20판)다. 에피소드마다 헤드라인 요소 1개를 둔다. L1~1,000에서는 신규 요소, 그 뒤에는 기존 요소의 재조합이나 티어2 변형(예: 얼음 + 선풍기)이 헤드라인이 된다.
2. **활성 요소는 한 판에 3개 이하**다(형태 1 + 물성·특수 ≤ 1 + 소품·환경 ≤ 1). 목표는 1개다.
3. **신규 공급 속도**: L1~100은 10판마다 1개(블록의 x1 칸), L101~1,000은 25판마다 1개, 그 뒤로는 2주 업데이트(100판)마다 1개다.
4. **중복 판정**: 최근 200판과 특징 벡터 거리가 임계치보다 가까우면 버린다.
5. **기준선**: L300 이후에는 고정한다. 톱니 진폭만 유지한다.
6. **재시도 시드 재추첨**: 배치, 소품, 목표는 고정한다. 바뀌는 것은 `stackSeed`(쌓는 순서), 금딱지 깊이 밴드, 봉인 딱지 앞면뿐이다(Peggle과 AB2 방식). 고정 시드는 오늘의 더미와 도전장에만 쓴다.
7. **결투판**: 라이벌 실력은 ★5를 상한으로 두고 고정한다. 난이도는 환경과 목표로 변주한다.
8. **공정성 게이트**: 다음 기준을 넘지 못한 판은 버린다.
   - 실력차(고수 봇 통과율 − 초보 봇 통과율) ≥ 0.30. 휴식판은 예외다.
   - 장외율 ≤ 15%
   - 판 길이 ≤ 45초(도전판)
   - 아까운 실패 비율 ≥ 40%
   - 운이 크게 작용하는 판(같은 입력에 시드만 바꿨을 때 결과 분산이 큰 판)은 목표 장수를 '안정 수율'까지 내린다.

### 4. 난이도 곡선

목표는 **실제 유저가 한 번 시도해서 통과하는 비율** p*(n)이다. 봇 통과율은 대리 지표다.

```
s      = ((n − 1) mod 10) + 1
p*(n)  = clamp( P[s] − D(n)·N[s] + I(n), 0.20, 0.97 )
D(n)   = 0.06 × min(1, (n − 1) / 299)        // L300까지만 6%p 어려워지고 이후 고정
N[s]   = 1 (x2·x3·x4·x7·x8), 0 (x1·x5·x6·x9·x0)   // 톱니 진폭은 고정
I(n)   = +0.05 (새 요소 데뷔판과 다음 2판)
예외   : n < 35 → P[5] = 0.80,  n < 59 → P[9] = 0.60
동네   : idx 49 = 보스(P[9]),  idx 50 = 동네 완성판(0.97)
```

| 칸 | 역할 | P[s] | 시도 수 | 표식 | `levels.js SLOTS.rate`(학습자 봇) |
|---|---|---|---|---|---|
| x1 | 새 요소 소개(유령 손가락 시범) | 0.95 | 1.05 | NEW | 0.92 |
| x2 | 연습 | 0.88 | 1.1 | – | 0.85 |
| x3 | 연습 + 기존 요소 1개 | 0.80 | 1.25 | – | 0.75 |
| x4 | 라이벌 결투 | 0.65 | 1.5 | VS | 0.60 |
| x5 | HARD | 0.62 | 1.6 | 빨간 불꽃 | 0.40 |
| x6 | 대박 휴식판 | 0.95 | 1.05 | – | 0.93 |
| x7 | 응용 | 0.78 | 1.3 | – | 0.68 |
| x8 | 정밀 | 0.70 | 1.4 | – | 0.60 |
| x9 | SUPER HARD 또는 보스 결투 | 0.40 | 2.5 | 보라 왕관 | 0.25 |
| x0 | 보상판 | 0.95 | 1.05 | 상자 | 0.93 |

- **리듬 규칙**: HARD·SUPER HARD 바로 다음 칸은 p* ≥ 0.89다. 3판 연속 안에 p* ≤ 0.62인 판은 1개까지만 둔다.
- **봇 목표와 유저 목표는 다르다.** SLOTS의 봇 목표(0.40, 0.25)를 유저 목표로 읽으면 시도 수가 2.5회와 4회가 되어 로얄 매치(1.6회, 2.5회)보다 가혹하다. 그래서 SLOTS를 '학습자 봇 목표'로 명시하고, 사내 플레이테스트 10~20명의 데이터로 봇 → 유저 보정 곡선을 만든다(E23).
- **초기 봇 측정(구 템플릿)에서는 톱니가 거의 평평했다**(normal 97% / hard 95%, 레벨당 16회). 보정표 `levels-cal.json`이 아직 없어서, 목표 클리어율로 추정한 k를 쓰고 있다. 손잡이 범위를 넓히고 레벨당 100회 이상으로 다시 재야 한다.

### 6. 별과 목표

| 목표 | 1★ | 2★ | 3★ | 목업 |
|---|---|---|---|---|
| N장 뒤집기 | 목표 달성 | 숨 1개 남김 **또는** 목표의 135% | 숨 1개 남김 **그리고** 135% | 들어감 |
| 금딱지 | 금딱지 뒤집기 | + 남은 숨 1 | + 남은 숨 2 | 들어감 |
| 결투 | 승리 | 판의 60% 이상 차지 | 75% 이상 차지 | 들어감 |
| 정확히 N장 | 정확히 N장 | 숨 1개 남김 | 첫 숨에 성공 | 없음 |

- **'가이드 항상 보기'를 켜면 별은 최대 2개다.** 마리오카트 스마트 스티어링의 교훈이다. 1★만으로도 진행이 되므로 접근성 이용자가 막히지 않는다.
- **3★는 숙련 목표다.** '동네 3★ 완주 도장'과 명인 기록으로 이어진다. 벽돌(메타 재화)은 첫 클리어에서만 나오므로, 3★가 진행을 막지 않는다.

### 7. 하드 레벨 규칙

1. **표식을 공개한다.** 맵과 진입 화면에 HARD(빨간 불꽃), SUPER HARD·보스(보라 왕관)를 띄운다 [결정 #21].
2. **첫 등장 시점**: HARD는 L35, SUPER HARD는 L59(로얄 매치 39/59 패턴, 가설).
3. **직후 휴식**: HARD 바로 다음 판은 p* ≥ 0.89이고, 싹쓸이 쾌감을 주는 대박 휴식판으로 둔다.
4. **보이는 도움만 준다.**
   - 3연패하면 '숨 안경'을 1회 무료로 준다. 1퍽 동안 정답 구간을 보여 준다.
   - 결투에서 3연패하면 '라이벌이 지쳤다'를 띄우고 ★을 1단계 내린 판을 공개적으로 제안한다 [결정 #20].
5. **금지**
   - 플레이어의 '세기 → 뒤집힘' 물리를 보정하는 것
   - 판 중간에 라이벌을 러버밴딩하는 것
   - 결과를 꾸민 near-miss
   - 불가능한 판
   - 결제 여부에 따라 난이도를 다르게 하는 것
6. **진입 화면에서 부스터를 권한다.** 보유분만 권하고, 판매 여부는 결정 #19에 따른다.

### 8. 라이벌 등장 주기

- **x4는 일반 결투, x9는 보스 결투나 SUPER HARD 도전**이다. 결투는 블록마다 2판으로 약 20%다.
- **동네마다 새 라이벌을 1명 소개**한다. 첫 등장은 그 동네의 첫 x4 칸이다. 라이벌은 고유 버릇(tell)을 갖는다.
  - 쌍둥이: 약한 숨을 2번
  - 할머니: 정밀하게 살살
  - 체육선생님: 선풍기를 켬
- **동네 보스는 idx 49**다. 그 동네의 골목대장(딱지왕 패거리)이다. **지역 보스는 200판마다 마지막 동네의 idx 49**로, 딱지왕 본인이다.
- **실력은 GDD §11.2 사다리(★1~★5)를 상한으로 두고 고정한다.** 200동네에 라이벌을 200명 만들지 않는다. 라이벌 약 12명을 지역 스킨으로 순환시킨다.
- **목업과 다른 점**: 목업은 25판마다 라이벌이 바뀐다(콩이 → 민수 → 지우 → 쌍둥이 → 할머니). 위 표의 주기에 맞춘다(P1).

| S2~ | 월드투어 도시(GDD §13.5 순서 또는 결정 #25) | 종 9개 × 현지 의상(멕시코는 치와와 + 루차, 일본은 시바 + 와가시) | 같은 문법 |

- **같은 종을 두 톤으로**: 기본판은 카와이로 아이·여성층을 겨냥한다. 시크릿은 장난꾸러기 톤으로 10대, 성인 남성, 라부부 팬층을 겨냥한다.
- **파츠 교체처럼 보이지 않게**: 시리즈마다 표정과 포즈를 새로 그리는 최소 품질선을 둔다.

### 4. 마감 4단, 컬러웨이, 동네 액자

| 축 | 내용 | 규칙 |
|---|---|---|
| 마감 | 기본 → 코팅 → 홀로 → 금박 | 중복으로 **확정** 승급(GDD §9.7 비율). 물리값은 같다 |
| 컬러웨이 | 시즌 한정 색 배합 1~2종('밤하늘', '벚꽃') | 시즌이 끝나면 절판. 추억 상점에서 구슬 2배 가격(GDD §9.5) |
| 동네 액자 | 동네를 완성하면 그 동네 배경 프레임을 두른 종 1장 | 배경 아트를 재활용해 싸게 만든다. 1만 판까지 200종 |

### 5. 시크릿 확률과 천장

라부부의 1/72는 실물 1개 기준이라 그대로 옮기지 않는다. 대신 하루 획득량에서 거꾸로 계산한다.

```
p      = ln 2 ÷ (a × D)       // a = 하루 그 시리즈 획득 장수, D = 시크릿 획득 목표 중앙 일수
예시   : a = 6, D = 21  →  p ≈ 1/180 (0.55%)
천장   : 그 시리즈 220장 획득 시 확정 (열심 유저가 6주 안에 닿는 값)
현상금 : 주 1회 '시크릿 현상금 판' 클리어 → 천장 카운터 +30
라이트 : a = 2 → 84장 + 6주 × 30 = 264 ≥ 220 → 현상금을 다 깨면 시즌 안에 확정
```

- 확률과 천장, 남은 카운터를 앨범에 공개한다.
- 앨범 칸은 처음부터 '?' 실루엣으로 보인다.
- 새 시리즈가 열릴 때 1칸을 미리 붙여 준다(부여된 진척: 완주율 19% → 34%).
- a 값은 E14 경제 시뮬과 E22로 다시 맞춘다.

### 6. 앨범 구조와 칸 수

| 구분 | 디자인 칸 | 1만 판 시점(하루 10판 ≈ 24시즌) |
|---|---|---|
| 영구 도감 | 30 | 30 |
| 시즌 시리즈 | 시즌마다 10 | 약 240 |
| 컬러웨이 | 시즌마다 1~2 | 약 36 |
| 동네 액자 | 50판마다 1 | 200 |
| **합계** | – | **약 500 디자인**(마감 4단을 상태로 치면 약 2,000) |

- 하루 10판 기준으로 6주(420판)마다 새 디자인 약 20개와 마감 목표가 생긴다. 새 목표가 '15판당 1개 이상' 나온다는 뜻이다.
- 1라운드에서 계산한 2,400칸(30종 × 20시즌 × 4)은 시즌당 신규 아트 10장과 맞지 않아 정정했다.

### 7. 획득처

| 경로 | 양과 주기 | 랜덤 | 돈 |

### 8. 돈과 랜덤의 경계 (머니 방화벽 유지)

1. 랜덤 공개는 무료 실력 플레이(봉인 딱지, 딱지판)에서만 한다.
2. 유료 재화로 딱지판, 봉인 딱지, 천장 카운터를 사는 경로는 0개다.
3. 유료 상품은 확정형이다. 유료 디자인은 별도 ID이고, 앨범 전용이며, 수집 레벨에서 빠진다(§14.2 그대로).
4. 1라운드에서 제안한 '시리즈 선택권(유료로 9종 중 1종 지정)'은 §14.2 결정 근거(돈으로 칸을 채우면 무료 중복이 판에 낼 딱지가 됨)와 충돌하므로 **보류**한다.
5. 한국 게임산업법 시행령의 확률형 아이템 적용 범위는 법률 검토 전까지 '무료라 괜찮다'고 전제하지 않는다 [결정 #28]. 확률은 어떤 경우에도 공개한다.

### 9. 교환과 투표 (P2, 서버 단계)

- **교환**: 친구끼리만 한다. ★1~3은 상시, ★4 이상은 '골든 퍽 주간'에만. 비용은 기존 재화(구슬)로 받고 새 토큰을 만들지 않는다(TCG Pocket 역풍).
- **딱지 총선거**: 연 1회, 46일간 연다. 판을 이길 때마다 1표를 얻고, 1위 종은 다음 시즌 금박 한정판이 된다. 단일 히어로에 기대는 것(Pop Mart 사례)을 팬덤 순환으로 분산한다. 최소 DAU 기준은 열린 질문이다.

### 10. 아트 규칙: 원판 = 얼굴

- 원판 지름 = 얼굴 지름이다. 원판 안에 작은 전신 캐릭터를 넣지 않는다.
- 눈 중심은 세로 55~60% 지점(아래쪽, 큰 이마), 눈 지름은 원판의 12~15%다. 볼 터치와 작은 입을 넣는다.
- 종을 가르는 돌출부(귀, 뿔, 꼬리)는 원 밖으로 하나만 낸다.
- 테두리 링에 희귀도를 넣는다(GDD §9.3 별 인쇄).
- '퍽' 할 때 더미 위 얼굴들이 함께 볼을 부풀려 반응한다. 피드백 2의 인과 연출과 이어진다.
- **트레이드 드레스 체크리스트**: 산리오·포켓몬과 실루엣과 대표 색이 겹치지 않는지 확인한다(예: 골든리트리버에 노랑 + 갈색 베레모 금지). 출시 전에 유사도를 검토한다. 생성 프롬프트에 타사 IP 이름을 쓰지 않는다.

- **자기 통제 피드백**: 내 얼굴을 길게 누르면 지난 숨 스냅샷을 본다.

- **숨 안경 부스터**: 1퍽 동안 단계 0 표시.
- **경계값 3/8/15는 초기값**이다. E17로 정한다.

### 2. 딱지 양 → 필요 세기 매핑 원칙

```
sweetHi(n) = clamp(0.45 + 0.5 × √((n − 1) / 19), 0.45, 1.12)   // 1장 0.45 · 5장 0.68 · 10장 0.79 · 20장 0.95 · 40장 1.12
sweetLo(n) = 0.78 × sweetHi(n)
물리 파워 = PHYS_SWEET × (원 파워 ÷ sweetHi(n))       // 정답 상한 = 물리 0.95
과파워   : 원 파워 > sweetHi(n) 이면 힘 증가 ×0.25 + 조준 흔들림(적은 더미일수록 크게)
```

1. **단조 증가, 오목 곡선**: 장수가 늘면 정답 숨도 늘지만 증가폭은 줄어든다(√). 한 번에 뒤집히는 장수가 6~7장에서 포화하므로(실측) 상한을 1.12로 둔다.
2. **모두에게 같다**: 레벨, 유저, 결제 여부와 상관없이 함수는 하나다. 결정론 시드를 쓴다. 숨은 보정은 없다.
3. **보이는 것만 필요 세기를 바꾼다**: 레벨 요소가 필요 세기를 바꿀 때는 눈에 보이는 성질로만 바꾼다(테이프 감은 딱지 = 무거움 = 더 세게, 얼음 = 미끄러움 = 살살). 겉모습이 같으면 효과도 같다.
4. **차이가 손가락으로 느껴질 만큼 넓게**: 390pt 폰에서 1장과 20장의 드래그 차이 목표는 손가락 약 1.5폭(약 85px 이상)이다. 지금은 64~82px다. 후보는 `pull` 0.55(84~107px)다(E20).
5. **텀블 시작점을 맞춘다**: 정답 상한이 물리 0.95인데 `sim.js`의 텀블 시작점(`sweet`)은 0.938이다. 그래서 정답 구간 맨 위(비율 0.987~1.0)에서 이미 텀블이 걸린다. 두 값을 같게 맞춘다(`PHYS_SWEET` → 0.935, 또는 `sim.sweet` → 0.95). GDD §20 결정 #13과 이어진다.

### 3. 절대 눈금 (정답과 무관하게 고정)

| 단서 | 사양 | 플랫폼 |
|---|---|---|
| 볼 반짝이 3단 | 흰 김(원 파워 ≥ 0.5) → 하늘색(≥ 0.75) → 금색(≥ 1.0) | 전체 |
| 들숨 음계 8단 | 원 파워 0~1.25를 8칸으로 나눠 장음계(도~도′). 칸이 바뀔 때 틱 | 전체(무음 iPhone에서는 반짝이만) |
| 진동 틱 | 칸마다 8ms | Android만(iOS 웹은 지원 안 함) |

- 문턱이 어떤 장수의 정답과 우연히 겹칠 수는 있다. 하지만 3단은 거칠어 정답 표시가 되지 못하고, 단계 안의 미세 조절은 감으로 남는다.
- 상대 피치(더미 대비 음높이)는 쓰지 않는다. '귀로 듣는 게이지'가 되기 때문이다.

### 5. 카메라와 입

| 안 | 내용 | 상태 |

- 마이크 모드에서는 '화면 아래 = 내 입'이 폰 마이크 위치와 맞는다. 실시간 숨 세기가 덩어리 크기가 된다(옵트인 유지, GDD §6.5).

### 6. 튜토리얼 '불기 학교' (글 없음, 첫 매치 = 골목 10장)

1. **T1(10장)**: 고스트 손가락이 맨 위 가장자리를 누르고 초록까지 당긴다. 0.25배속 클로즈업으로 쐐기를 보여 준다.
2. **T2(약 6장)**: 초록 구간이 미끄러지며 줄어든다. 지난 볼 실루엣과 이번 초록 볼을 겹쳐 보여 준다.
3. **T3(2~3장)**: 초록이 아주 작다. 일부러 크게 불게 해서 흔들림을 1회 겪게 한다.
4. **상대 턴**: Lv1~2 라이벌이 거의 정답 크기로 볼을 부풀려 시연한다.
5. **이후**: 레벨 1~10(3 → 16장)이 곧 가변 연습이고, 게이지 은퇴 단계가 이어진다.
