# 재윤님·코덱스 PDF '퍼크, 어떻게 떠서 뒤집히는가' 검토 (2026-10-15)

## 🧭 핵심 가설

- **가설 (프레임 독립 판독으로 확인됨)**: PDF의 관찰은 맞다. 높은 더미는 **위부터 들리고 아래로 번진다**. 층이 갈라지고, 고개는 **숙이며 불다가 들린 뒤에 든다**. 큰 쓸기는 없다.
- **가설 수정 (v1 코어와 충돌, 미검증)**: 실물에서 높은 더미(25~35장)를 넘긴 입은 **꼭대기 높이에서 조금 위**(꼭대기 위 0.3~1.1D)에 있었고, 부는 동안 **아래로 숙였다**. 우리 v1 코어는 '입은 바닥(12.5 mm), 바람 자국을 위로 쓸기'라서 기하가 반대다.
  - v1은 꼭대기 입을 바닥 입의 0.3~0.6배로 낸다. 하지만 v1에는 아래로 부는 바람의 벌점이 미리 들어 있고 윗면 흡입은 없다. 그래서 v1은 이 차이를 판가름할 자격이 없다.
  - 영상 A(꼭대기 입으로 대부분 넘김)는 v1 예측(30장 8.5장, 40장 6.8장)에 대한 **실물 반례 후보**다.
- → 코어(§10-4 'v1으로 갈지')는 **보류**한다. 판가름 순서는 다음과 같다.
  1. v1·정직 엔진에 '꼭대기 입 + 숙이며 불기 + 말린 테두리 들기' 팔을 넣어 잰다.
  2. 실물 측면 촬영(편집 없음, 240 fps, 자)으로 입 높이·고개 방향·들림 순서·시간을 확인한다.

## 1. PDF 평가

- **좋은 점**
  - 관찰·해석·제안을 나눠 적었다.
  - 측정 한계를 밝혔다: 방송 슬로·리플레이·2배속 → 실제 시간·cm·m/s·N·장수를 뽑지 않음.
  - '들림 ≠ 뒤집힘', '더미 = 여러 장의 집합', '두 단계 사이가 길면 내려앉고 이르면 평평한 면에 힘이 걸림'은 v1 시작 시각 산(30장 4.4 / 14.2 / 20.1 / 17.0 / 11.6장)과 같은 말이다.
- **약한 점**
  - 분출 곡선(퍼 스파이크 → 크 둘째 봉우리)은 PDF 스스로 '게임용 예시'라 했다. 프레임으로는 두 분출을 가를 수 없다.
  - 15쪽 입 높이 범위(0.05D~H+0.5D)는 실제 시범 샷(꼭대기 위 0.3~1.1D)을 다 담지 못한다.
  - '대량 = 낮은 층 경계 겨냥'도 관찰과 다르다. A의 대량 성공은 꼭대기 입으로 위부터 벗긴 결과다.

## 3. v1 실험 (`tools/coresweep/pdfcheck.mjs`, 시드 401~412·413~424, 물리 손잡이 무수정, `sweepmap verify` 9/9)

| 꼭대기 입 ÷ 바닥 입(최선 고정) | 0.56 [0.43, 0.68] | 0.46 [0.37, 0.55] | 0.34 [0.22, 0.47] |
| 가운데 입 ÷ 바닥 입 | 0.99 | 0.95 | 1.07 |
| 3.75 mm 입(입술이 책상에 닿음) ÷ 바닥 입 | 0.47 | 0.04 | 0.00 |
| 위 1/4이 먼저 10°에 닿은 샷 (입 높이 5가지 모두) | 192/192 | 192/192 | 192/192 |
| 진짜 두 번 분출(간격 g > 0) ÷ 지금 코어 튕김 | 0.54 / 0.56 | 0.42 / 0.61 | 0.44 / 0.78 |
| 지금 코어 튕김 ÷ 바닥 입 최선 고정 | 0.96 | 1.05 | 1.27 |

- **v1 안에서의 결론**
  - 꼭대기 높이에서 수평으로 부는 숨은 손해다. 격자 밖 탐침(더 짧고 약한 숨)을 넣어도 같다.
  - 퍼 → 간격 → 크로 두 번 나눠 부는 것은 한 숨 안에서 쓸어 올리는 것보다 못하다.
  - 40장 '산'(1.31)은 숨이 넘친 기준선과 잡음 바닥(±15~25%) 안의 결과라 예외로 보지 않는다.
- **판별력 없음**: 위가 먼저 기우는 것은 v1 모델의 성질이라 입 높이와 무관하게 나온다.
- **가장 큰 구멍**
  - v1은 아래로 부는 바람에 벌점을 준다(lipPress 0.5, lipPressBlast 1.1).
  - v1에는 윗면 흡입과 말린 테두리가 바람을 잡는 기전이 없다.
  - 그래서 '꼭대기 입 + 숙이며 불기'를 v1이 지는 것은 모델이 미리 정한 답일 수 있다.
  - 실물 A가 그 반례 후보다.
- 원자료: `tools/coresweep/data/pdf/pdf401.jsonl.gz`(5,760샷). 재현: `node tools/coresweep/pdfcheck.mjs report tools/coresweep/data/pdf/pdf401.jsonl.gz`.

## 4. PDF 설계 제안 → 우리 설계

| PDF | 판단 |
|---|---|
| '크' = 들린 뒤 두 번째 분출로 방향·지속 조절 | 기능은 우리와 같다('들린 테두리에 맞는 때 힘을 다시 걸기'). v1에서는 끊고 다시 부는 것이 한 숨보다 못하다. → '크'는 한 숨을 이어 가며 조절하는 것으로 읽는다. 실물의 조절 방향(위로 쓸기 vs 아래로 숙이기)은 미결이다 |
| 입 아이콘 드래그로 높이·거리·좌우·각도 조준 | v1에서는 이득이 없다. 다만 v1이 꼭대기 근처 바람을 다룰 자격이 없어서 **보류**다. 높이 조준을 되살리면 재윤님 10-14 결정을 뒤집는 것이다 |
| 놓으면 퍼 → 들린 직후 다시 눌러 크(두 번 누르기) | 손을 떼는 동안 숨이 끊기고, 반응 과제가 된다(첫 들림 33~60 ms). 미뤄 둔 콤보(훗 → 퍽)와 같은 질문이라 함께 다룬다 |
| 면 판정 ±20°, 사이는 대기 | 채택하지 않는다. 실물은 부채꼴로 비스듬히 겹쳐 눕는다. 우리 faceUp > 0.2를 유지하고, 모서리로 선 장은 BLOCKERS A7로 둔다 |
| 정지 판정 v < 0.05 D/s, ω < 0.25 rad/s 0.25초 | 크기는 같다. 우리는 판정이 셋으로 갈려 있다(PvP stepJudge, 솔로는 프레임 수, 봇은 isSettled). → 코어 전환 때 하나로 통일한다(채택) |
| 호흡량 0이면 자동 종료 | **우리 규격의 빈칸**이다. 숨 풍선이 푸어억 도중에 바닥나는 경우가 정의되어 있지 않다. → 푸 상한을 남은 칸으로 묶는다(채택) |
| 실패 진단표 | '더미가 밀리기만 함' 카드를 추가할 후보다(cuecheck 검증 뒤). 처방 문구는 §5 원칙(정답 미리 안 보임)에 맞게 '바꿀 축 하나' 아이콘까지만 쓴다 |
| 테스트 6개 | 1~4번은 이미 있다(PvP 해시·pvpsync). '30/60/120 fps'는 솔로 정지 판정 통일과 함께 다룬다 |
| 실물 확인 3단계 | v2 §7.9의 R3를 다시 쓴다. 편집 없는 측면 + 정면, 눈금, 입–더미 거리, 20·30·40장, 한 변수씩 바꾼다(첫 변수는 고개 방향과 시각) |
| 연출 | 당기는 동안 얼굴이 낮아지며 다가가고, 숨 끝에 입이 벌어진다. 그림 연출로만 채택한다 |

## 5. 다른 문서에 반영할 단서

- 04 §3의 '들림 33~60 ms'는 릴 화면 녹화라 재생 속도를 모른다. B컷에도 '2배' 표시가 있다. → '찰나' 해석의 받침을 약한 근거로 낮춘다.
- 이 방송은 무늬 면을 위로 쌓고 흰 면이 위로 오면 뒤집힌 것으로 보인다(저해상도, 미검증). 우리 게임은 그림을 아래로 놓고 시작한다(BLOCKERS A2 기억 대조 자료).
- 영상 속 책상에는 원이나 경계 표시가 보이지 않는다. 착지는 대략 1~2D 안이다(BLOCKERS G9 자료).
