# 클래시 로얄 첫 세션 → PUFF! 벤치마크

> 출처: 재윤님이 직접 찍은 클래시 로얄 첫 실행~몇 판 캡처 69장(IMG_6254~6322). 타사 화면이라 이미지는 저장소에 넣지 않고 로컬 캐시에서만 봤습니다. 다른 플레이어 이름·개인정보는 옮기지 않았습니다. 프레임 번호는 그 캡처 파일 이름입니다.

## 🧭 핵심 가설

**가설**: 클래시 로얄 첫 7분이 쉽고 비싸 보이는 까닭은 콘텐츠 양이 아니라 세 가지 규칙입니다.
1. 한 번에 동사 하나만 시킵니다. 손가락 하나를 쓰고, 시간을 멈추고, 나머지 화면은 어둡게 합니다.
2. 행동한 직후 보상이 그 자리에서 진행 바로 차고, 손가락이 쓸 곳까지 데려갑니다.
3. 화면 문법이 하나입니다. 단추의 턱, 숫자의 그림자, 편 색, 외곽선 없는 세 단계 명암이 어디서나 같습니다.

→ 그래서 새 콘텐츠를 만들기 전에 이 규칙부터 쓸기 연습판에 입히자고 제안드립니다. 대상은 세 박자 코치, 결과 카드, 단추, 빛과 그림자입니다. 잘됐는지는 세 가지로 판가름합니다. 첫 숨 성공률, 결과 화면에서 '한 숨 더'를 누르는 비율(GDD §12.5), 얼굴 전후 비교를 보신 재윤님 판단입니다.

(대부분 미검증입니다. 근거는 정지 캡처 69장 관찰이고, 시간과 움직임은 캡처 사이 차이로 추정했습니다. 원본 픽셀로 잰 것은 '확인됨'으로 표시했습니다. 정사영 카메라, 결과 화면 50% 덮개, 그림자가 바닥 밝기의 0.53배인 점, 바닥과 가장자리의 밝기 차이가 여기에 해당합니다.)

- 원본은 제3자 화면이라 저장소에도 게시물에도 넣지 않았습니다. 축소본은 스크래치 폴더에만 있습니다.
- 다른 플레이어 이름, 클랜 이름, 계정 정보는 적지 않았습니다.
- 빠르게 보실 모음: `(로컬 캐시) cr-bench/picks.jpg` (8장, ★ = 아래 D의 3장)

## B. 베끼지 말 것

**1. 미스터리 상자의 '?' 토큰 등급 굴리기** (6308–6313, 6317)
- 왜 빼나:
  - 이미 정해진 결과를 굴리는 척하는 꾸민 '아깝다' 연출입니다. GDD P2 '결과는 진짜'와 부딪힙니다.
  - '돌리기·뽑기'는 §11.7 금지어입니다.
  - 유료 랜덤 규제(PEGI, 한국 확률 공개)에 걸립니다.
- 대신: **희귀도 = 무대 색**(파랑 → 주황 → 보라)만 가져옵니다.

**2. 무작위 내용인데 '?' 카드로 뜸 들이기** (6283)
- 왜 빼나: 뜸 들이기는 내용이 정해져 있고 미리 보일 때만 정직합니다.
- 대신: 우리 딱지판은 지금 무작위라, 뜸 연출을 넣기 전에 확률부터 공개합니다.

**3. 첫날부터 보석 100, 상점 탭 맨 왼쪽, 두 판 뒤 '+' 단추** (6286, 6319)
- 왜 빼나: 유료 재화로 가는 동선입니다. 전연령 게임이고 13세 미만은 친선이 기본이라 맞지 않습니다.
- 대신: 유료 재화는 두지 않습니다. 결제 팝업은 캡처에 없었고, 그 뒤 흐름은 미검증입니다.

**4. 업그레이드하면 능력치가 오름** (6297 '+7 +6 +69')
- 왜 빼나: 물리 세기가 오르면 돈을 쓴 쪽이 이깁니다.
- 대신: 숫자 연출만 빌립니다. 오르는 것은 겉모습과 수집 레벨뿐입니다(코팅은 물리 불변, GDD).

**5. 상자 칸과 대기 시간** (6286 상자 칸 2개, 타이머는 캡처에 없어 미검증)
- 왜 빼나: 판 밖 대기 에너지를 만들면 '기다림을 돈으로 줄이기'로 이어집니다.
- 대신: 지금 무료 딱지판에는 2분 대기(`SHEET_COOLDOWN`, 목업 값)가 있습니다. 실제 값을 정할 때도 돈으로 줄이는 길은 붙이지 않습니다.

**6. 첫 조작 전 말풍선 4번, 시작하자마자 나이·약관·쿠키 3연속** (6259–6262, 6255–6258)
- 왜 빼나: 첫 퍽 12초 이하 기준보다 느립니다. 우리 원칙은 연령을 그 기능을 처음 열 때 묻는 것입니다(GDD §12.1).
- 대신: 법적 고지가 꼭 필요하면 로딩 바가 차는 동안 겹쳐서 처리합니다.

**7. 클랜 검색 팝업을 바로 띄우고 낯선 사람 목록 보여 주기** (6320–6322)
- 왜 빼나: 아이 안전 문제가 있습니다.
- 대신: 코드로 들어오는 친구 대결만 둡니다.

## C. 아트·월드에서 배울 것 → 교실 책상 장면

**C1. 카메라와 더미 구도**
- 클래시 로얄:
  - 정사영 카메라이고, 내려다보는 각도는 약 53°입니다(6305에서 길 중심이 위아래로 같은 x에 있음, 확인됨).
  - 판이 화면 너비의 89%, 높이의 14~75%를 차지합니다.
  - 카드 바는 화면 아래 18%이고 판을 가리지 않습니다.
  - 경기 시작 때 9~10% 넓은 전경을 보여 준 뒤 당깁니다(6300 → 6302).
- 우리 지금: D 조준 시점은 12°(세로 화면), FOV 50입니다. 숨이 나가면 +8°, 거리 ×1.45로 물러납니다(`sweepViewD` 5187).
- 제안:
  - ③을 놓은 뒤 0.3~0.5초는 지금 낮은 시점을 그대로 둡니다. 들리는 순간이 손맛이기 때문입니다.
  - 그다음 0.6초 동안 각도를 45~50°로 올리고, FOV는 50 → 28, 거리는 ×1.87로 늘립니다(같은 폭 유지). 정사영에 가까운 '장난감 판' 느낌이 납니다.
  - 착지, OUT, 결과는 이 시점에서 보여 줍니다. 반지름 5 원이 화면 너비 90% 안에 들게 합니다.
  - 책상(22 u)이 화면 밖으로 넘치면 OUT은 화면 끝 화살표로 알립니다. 정확한 프레임은 착지 분포로 정해야 합니다(미측정).
  - 판을 시작할 때는 거꾸로, 전경을 1.0초 보여 주고 0.6초 동안 조준 시점으로 당깁니다.

**C2. 판과 배경**
- 클래시 로얄 (확인됨, 6305):
  - 놀이 바닥은 밝기 차이가 ±3%로 조용합니다.
  - 가장자리 나무는 20% 어둡고 밝기 편차가 8배입니다.
  - 가장자리 소품은 화면 끝에서 잘리고, 판 안에는 하나도 없습니다.
- 제안:
  - 아웃 경계 안의 나무결 대비를 ±3~4%로 낮춥니다.
  - '딱지왕' 낙서(`woodTexture` 211)와 하트는 경계 밖 구석으로 옮깁니다.
  - 경계 밖에 굵은 문방구 소품을 둡니다: 필통, 지우개, 몽당연필, 자, 공책 귀퉁이. 판보다 20% 어둡게, 화면 끝에서 잘리게 두고, 그림만 있고 물리는 없습니다.
  - 칠판 배경(`classroomBackdrop` 257)은 채도를 30% 낮추고 살짝 흐리게 합니다.

**C3. 빛과 그림자**
- 클래시 로얄: 그림자가 카메라 쪽(화면 아래)으로 떨어지고, 바닥 밝기의 0.53배이며 가장자리가 부드럽습니다(확인됨). 금속만 반짝이고 나머지는 무광입니다.
- 우리 지금:
  - 해가 (5,11,6), 즉 앞쪽 오른쪽에 있습니다. 그래서 그림자가 더미 뒤로 숨습니다.
  - 그림자 카메라 범위는 ±9 u인데 책상은 가로 ±11 u라, 책상 끝에서 그림자가 끊길 수 있습니다(코드로 본 추정).
- 제안:
  - 해를 뒤쪽 오른쪽 약 (4,12,−6)으로 옮깁니다.
  - 반구광을 올리고, 그림자 밝기를 바닥의 0.5배로 맞춥니다.
  - 그림자 범위를 ±12 u로 넓힙니다.

**C4. 더미는 우리의 '건물'**
- 클래시 로얄:
  - 탑의 돌 블록마다 밝은 윗모서리와 어두운 이음매가 있어 한 장씩 셀 수 있습니다.
  - 유닛과 탑의 크기 비는 1 : 2.4이고, 보상(왕관)은 유닛의 약 2배로 과장합니다.
- 제안:
  - 딱지 옆면 위쪽 15%에 밝은 띠, 아래쪽 10%에 어두운 이음매를 넣습니다. 윗면이 장면에서 가장 밝게 하고, 외곽선은 쓰지 않습니다(paper.js 재질, art.js 옆면). ① 고리를 칠 때 몇 장째인지 세기 쉬워집니다.
  - 보상으로 보여 주는 딱지(결과 화면, 앨범으로 날아가는 장면)는 책상 위 크기의 약 2배로 키웁니다.

**C5. 캐릭터와 얼굴** (재윤님이 '싸 보인다'고 하신 부분)

| | 클래시 로얄 킹 (6259 확대) | 우리 얼굴 B (`face.js`) |
|---|---|---|
| 선 | 잉크 외곽선이 없음. 명암과 테두리광으로 덩어리를 만듦 | 갈색 잉크선 `INK #2a1a12`, `LW 0.012`가 전체에 있음 |
| 어두운 덩어리 | 눈썹·콧수염·턱수염 3덩이. 회흑색(`#191b21`~`#4a4e53`)에 홈 3~4줄 | 곱슬머리를 잔선으로 그림 |
| 입 | 거의 검정인 입 속 + 위아래 이빨 띠. 입술은 피부 그늘로만 처리 | 빨간 꽃잎 모양 입술 |
| 붉은 기 | 코끝에만 있음 | 볼의 분홍 원 + 빨간 입술 |
| 눈 | 작고, 흰 반사점 1개 | 크고 동그란 잉크 눈 |
| 반복 | 같은 자리·같은 포즈를 8번 다시 씀. 입 벌림만 달라짐 | 12컷 |

- 원인 가설(미검증): 외곽선을 그은 2D 얼굴이 PBR로 렌더한 3D 책상 위에 얹혀서, 화면 안에 그림 방식이 두 가지로 섞여 있습니다. 판가름은 재윤님 눈으로 합니다.
- 1단계 (M, 우리끼리 가능):
  - 얼굴 안쪽 잉크선을 빼고, 바깥 실루엣만 진한 피부색으로 남깁니다.
  - 볼·코·턱에 3단 명암을 넣고, 반대편에 하늘색 테두리광을 넣습니다.
  - 머리와 눈썹은 회흑색 큰 덩어리에 홈 3줄로 그립니다.
  - 뽀뽀 입은 빨간 꽃잎 대신, 피부보다 조금 붉은 도톰한 고리에 위쪽 반사광과 아래쪽 그늘로 그립니다. 입 속은 `#1a0b0b`입니다.
  - 붉은 기는 코끝과 볼에만 둡니다.
  - 12컷을 핵심 4컷(대기·모음·초록 퍼·돌풍)으로 줄이고 컷마다 품질을 올립니다.
  - 1인칭 볼·입술(`drawFPV` 790)은 ③ 동안만 크게 보여 줍니다.
- 2단계 (L, **재윤님 결정과 에셋 필요**):
  - 3D 얼굴 조각 하나를 만들어 미리 렌더한 스프라이트(볼 8단계 × 입 3모양)로 바꿉니다. Tripo는 유료 크레딧이라 승인이 필요합니다(BLOCKERS B6, GDD 결정 12). 재윤님이 모델을 주셔도 됩니다.
  - 안내 마스코트 한 명을 화면 왼쪽 아래에 높이 약 30%로 두고, 말풍선 꼬리는 입 쪽을 향하게 합니다.

**C6. 움직임과 효과**
- 클래시 로얄:
  - 효과는 짧고 굵은 한 방입니다. 소환은 발밑의 납작한 흰 연기 고리, 맞으면 실루엣 전체가 보라로 번쩍, 부서지면 파편이 튀고 잔해가 경기 끝까지 남습니다.
  - 월드 사건과 HUD가 같은 박자에 반응합니다. 탑이 무너지는 순간 왕관 칸이 1/3에서 3/3으로 바뀝니다.
- 제안 (그림만 바꿈):
  - 착지 팝은 7번 그대로입니다.
  - 딱지가 뒤집히는 바로 그 프레임에 HUD 장수를 +1 합니다.
  - 분필 가루 자국은 판에 남겨 둡니다.
  - 입자는 둥근 점 대신 종이 조각 모양으로 바꿉니다.
  - 꽃가루(`fx.confetti`)는 지금 6색인데, 내 편 색 꽃잎 한 가지로 바꿉니다.
- 결과 화면:
  - 카메라는 그대로 두고 검정 50%를 덮습니다(확인됨).
  - 딴 것이 0.25~0.35초 간격으로 하나씩 앉습니다(간격은 추정). 앉을 때마다 1.15배로 튀고 섬광이 나며, 효과음 높이가 한 계단씩 오릅니다.
  - 단추는 맨 마지막에 나옵니다.

## E. 적용 계획 (조각마다 1시간 안팎, 끝나면 폰에서 바로 확인)

진행 방식은 조각마다 같습니다.
1. 빌드합니다.
2. 아티팩트 게시 전에 `artifact-check`를 돌립니다.
3. 같은 링크에 다시 게시합니다.
4. 재윤님이 폰에서 보시고 다음 조각으로 갈지 정하십니다.

⚑ = 재윤님 결정 필요, 🎨 = 에셋 필요입니다.

**1단계: UI 체계**
1. 단추 CSS(세 색, 못 누르는 상태 4가지) → 폰: 홈과 결과 카드의 전후 비교 · 확인: build, artifact-check
2. 숫자 글자 규칙(얇은 테두리, 아래 그림자, 초록 '+N') → 폰: 결과 카드 숫자 · 확인: build
3. 결과 카드 한 길(같은 더미 단추만 늦게 커짐, 나머지는 작게) → 폰: 쓸기 결과 카드 · 확인: sweepplay
4. 결과 연출(장수 세어 올리기 → 별 착지 → 칩 1개, 진동 tapMedium) → 폰: 결과 화면 녹화 · 확인: sweepplay, app-bridge-check

**2단계: 세 박자 온보딩**

5. 코치 말 한 줄, 개발 이름표는 ⚙ 안으로 → 폰: 첫 3숨 스크린샷 · 확인: sweepplay
6. 1숨은 ③만(①② 잠금 표시) → 폰: 새로 열어 첫 숨 · 확인: sweepplay (12)에 칸 추가
7. 2숨은 ①+③, 3숨은 셋 다, 30장 시작, 평생 진행값 저장 → 폰: 처음부터 3숨 · 확인: sweepplay · ⚑ '학교는 30장' 동의
8. 스포트라이트 덮개(목표 하나만 밝게) → 폰: 박자별 스크린샷 3장 · 확인: sweepplay
9. 흰 장갑, ③ 끌기 시범, 1.6초 눈금 → 폰: 시범 녹화 · 확인: sweepplay, feelclock check
10. ③ 미리 보기(손가락 위 이름표, 숨 막대 칸, 책상 밖 빨강) → 폰: 당기는 중 화면 · 확인: sweepplay, `sweepgame ctl`(자체 책상 식 0건)

**3단계: 월드·아트**

11. 해 방향, 그림자 0.5배, 그림자 범위 ±12 → 폰: 더미 전후 비교 · 확인: papercheck
12. 딱지 옆면 밝은 띠와 이음매 → 폰: 40장 더미 확대 · 확인: papercheck
13. 판 정리(나무결 대비 낮추기, 낙서 밖으로, 칠판 채도 낮추기) → 폰: 전경 스크린샷
14. 가장자리 문방구 소품(1차는 절차 생성 저폴리) → 폰: 전경 · 🎨 진짜 모델은 나중에
15. 숨 뒤 전경 카메라, 시작 전경 → 당김 → 폰: 한 숨 녹화 · 확인: feelclock check(결과가 다르면 run 하고 06 §8.11 표 갱신), sweepplay · ⚑ 손맛 판정
16. 공중 그림자, 착지 팝, OUT 회색 연기, 종이 조각 입자 → 폰: 한 숨 녹화 · 확인: feelclock check
17. 결과 50% 덮개, 한 색 꽃가루 → 폰: 결과 녹화 · 확인: sweepplay(PvP 결과까지 바꾸면 pvp-check)
18. 얼굴 1단계 시안(선 빼기, 명암, 입 속, 4컷) → 폰: 얼굴 시트 전후를 나란히 1장 · ⚑ 재윤님 눈 판정
19. 얼굴 2단계(3D 조각 → 스프라이트) + 안내 마스코트 → 폰: 4컷과 코치 화면 · ⚑🎨 Tripo 유료 크레딧 승인 또는 모델 제공

**4단계: 나중(경제·메타, 결정 먼저)**

20. 첫 실행 = 불기 학교 1/3 · ⚑ 레벨도 D 조작으로 옮길지
21. 홈 잠금, 여는 조건, n/3 막대 → 폰: 첫 실행 홈 · 확인: artifact-check
22. 보상 한 장씩, 남은 개수, 획득 요약(`finishLevel`) → 폰: 레벨 결과 녹화
23. 중복 진행 바, NEW 도장, 첫 딱지판 고정 · ⚑ 딱지판 무작위 유지 여부와 확률 공개
24. 숨 풍선 HUD(엘릭서 문법) · 확인: balloon-check · ⚑ 연결 시점
25. 이름·나이 팝업(친구 대결 처음 열 때), PvP 결과 도장 · 확인: pvp-check, `NET=artifact` pvp-check

**먼저 정해 주시면 좋은 것 세 가지**
- ⚑ 레벨에도 세 박자를 쓸지 (20번)
- ⚑ 얼굴 2단계에 유료 3D를 쓸지 (19번)
- ⚑ 딱지판 무작위를 유지할지 (23번)

1~17번은 결정 없이 바로 시작할 수 있습니다.
