# 막힌 것 · 확인 필요 · 결정 대기 (2026-10-12, 목업 v0.1)

## 🧭 핵심 가설

- **목업의 성패는 "한 번 퍽 했을 때 손맛"으로 판가름 난다.** 아래 막힘은 대부분 그 손맛을 실기기에서 확인하지 못한 데서 온다. (미검증)
- **원작 룰 해석 두 가지가 재윤님 기억과 다를 수 있다.** 매 턴 다시 쌓기, 그림면 아래로 시작. 틀리면 조작감 전체가 바뀌니 가장 먼저 확인한다. (미검증)

## A. 재윤님 확인이 필요한 원작 룰 (기억 대조)

| # | 질문 | 목업 현재 구현 | 대안 |
|---|---|---|---|
| A1 | 한 턴이 끝난 뒤 남은 딱지를 **다시 원기둥으로 쌓았나**, 흩어진 채로 다음 사람이 불었나? | 매 턴 다시 쌓음 (턴마다 같은 '퍽' 쾌감, 읽기 쉬움) | 흩어진 채로 두기. 납작하게 깔린 딱지는 거의 안 뒤집혀서 후반이 지루해질 위험이 있다 |
| A2 | 더미를 **그림이 아래로 가게** 쌓고, 그림이 위로 오면 '뒤집힘'이었나? | 그림 아래로 시작. 뒤집히면 캐릭터가 공개되어 수집의 쾌감과 겹침 | 반대 방향 |
| A3 | 한 번에 **한 번만** 불고 상대 차례였나, 뒤집으면 한 번 더 불었나? | 한 번 불고 무조건 교대 | 뒤집으면 연속 (당구식). 실력 차가 커짐 |
| A4 | 선공은 어떻게 정했나? | 가위바위보 | 판돈 많이 건 쪽, 진 쪽 선공 등 |
| A5 | 부는 위치는 더미 **옆면**이었나, 위에서 내려 불었나? | 옆면 (원기둥 높이·좌우 조준) | 위에서 불기 모드 |

## B. 기술적으로 막힌 것 / 우회한 것

| # | 막힘 | 영향 | 우회 / 다음 |
|---|---|---|---|
| B1 | **실기기 손맛 미검증.** 이 작업 환경은 헤드리스 브라우저뿐이라 터치감, 진동, 소리, 마이크를 실제로 느껴보지 못했다 | 감도(당김 길이 = 화면 짧은 변의 42%), 슬로모 길이, 소리 볼륨이 실제로 맞는지 모름 | 재윤님 폰 플레이 피드백으로 튜닝. 수치는 `main.js` 상단 상수에 모아둠 |
| B2 | **바람은 실제 유체 시뮬레이션이 아니라 근사.** 더 세게 불수록 계속 많이 뒤집히는(단조) 성질이라, 물리만으로는 '너무 세면 손해'가 안 생긴다 | 스윗스팟을 물리로 못 만듦 | 게임 규칙으로 해결: 과파워면 조준이 흔들리고 파워 상한이 걸린다. 자동 튜너(`tools/tune.mjs`)로 분포를 맞춤 |
| B3 | **claude.ai 아티팩트 뷰어는 마이크 권한을 줄 수 없다** | 공개 링크 버전에서는 '진짜 불기' 불가 | 로컬 `dist/puff.html` 에서만 마이크. 아티팩트 버전은 터치 전용 |
| B4 | **아티팩트 뷰어에서 WebAssembly(Rapier 물리) 실행 허용 여부를 이 환경에서 확인할 수 없다** | 공개 링크에서 물리 로딩이 실패할 수 있음 | 실패하면 안내 문구가 뜬다. 그때는 로컬 파일 사용. 근본 대안은 순수 JS 물리 또는 서버 시뮬레이션 |
| B5 | **리서치 환경 제약.** 컨테이너 프록시가 위키·나무위키·jsDelivr 등을 차단했고, 리서치 에이전트들이 공유하는 검색 한도(200회)가 중간에 소진됐다 | 수집 메타와 PvP 관점 일부가 기억 기반(confidence low) | 리포트에 (미검증) 표시. 수치는 재확인 필요 |
| B6 | **아트는 캔버스 절차 생성 2D.** 3D 메쉬나 AI 이미지는 아직 없음 | 클래시·로얄킹덤급 룩과 거리가 있음 | Higgsfield(generate_image / generate_3d)와 Figma(generate_image) 도구가 세션 목록에 있다(실제 동작은 미확인). **유료 크레딧을 쓸 수 있으므로 재윤님 승인 후** 진행. TripoSG 로컬 검증은 G1 메모리 참고 |
| B7 | **효과음이 전부 합성음** | '탁', '퍽' 질감이 실물보다 약함 | 실제 딱지 녹음 샘플 3~5개 확보 → 오음계 피치 시프트 |
| B8 | **G2 레포에 기준 브랜치(main)가 없다** | 작업 브랜치가 유일 브랜치라서 PR을 만들 수 없음 | main 생성 여부는 재윤님 결정 (지정 브랜치 외 푸시는 허락 필요) |
| B9 | **메모리 레포:** '가설 먼저' 규칙을 다른 12개 프로젝트 메모리에 일괄 추가하는 작업이 자동 권한 검사에서 차단됨 | G2 메모리, G2 CLAUDE.md, 기존 admin 메모리에만 박혀 있음 | 재윤님이 허락하면 일괄 추가 |
