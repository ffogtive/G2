# PUFF! — 딱지 불어먹기 (G2)

> 후~ 불고, 뒤집고, 가져가! · Blow. Flip. Keep.

1990년대 한국 문방구 '동그란 딱지 불어먹기'를 남녀노소·글로벌 아케이드로 옮기는 프로젝트.

## 바로 해보기

- **`dist/puff.html` 을 브라우저로 열기** (더블클릭). 인터넷 없이도 됨. 폰이면 파일을 폰으로 옮겨 Chrome/Safari 로 열기.
- 조작: **딱지 더미를 누르고 → 아래로 당겼다가 → 놓기 = 퍽!**
  - **누른 곳 = 바람이 닿는 곳** (좌우·높이). 맨 위 = 안정, 가운데 = 대박 아니면 꽝. 옆을 불면 반대쪽 대각선으로 굴러 넘어간다
  - 다시 쌓은 더미엔 삐져나온 딱지가 있다 — 그 틈을 정확히 노리면 공기가 밑으로 파고들어 크게 뜬다
  - 당긴 길이 = 숨. 볼이 부풀어 얼굴 둘레 **숨 주머니 고리에 닿으면 '꽉'** — 들숨 소리가 끊기고 손끝이 톡. 더는 안 들어간다
  - 정답 숨은 늘 꽉보다 아래, **더미가 높을수록 꽉에 가깝게**. 초록(튜토리얼 게이지) = 최대로 넘어감
  - 약하면 들썩만, 너무 세면 돌풍이 딱지를 **분필 원 밖**으로 날려 무효(OUT). 꽉에서 오래 버티면 콜록!
- 홈 **PLAY = 레벨 지도**(캔디크러시식, 10판마다 HARD·SUPER HARD·휴식판). **자유 대전**은 판돈 걸고 AI와 한 판.
- 게이지(초록/빨강)는 처음 몇 번만 보이고 사라진다 → 쌓인 양을 보고 감으로. 볼 반짝임 색과 숨소리 음계가 '내 숨의 크기' 자.
- 앨범 → '다음 테마 시안' 탭: 동물 크리처 × 분식 의상 시안(리서치 1순위).
- 홈 ⚙ 손맛 튜닝: 당김 거리·바람 세기·슬로모·상대 실력·가이드 항상 보기·꽉 버티는 시간.
- 홈 화면 `Mic blow` 를 켜면 **누른 채로 마이크에 진짜 "후~"** 로 파워를 낸다 (로컬 파일 실행 시).
