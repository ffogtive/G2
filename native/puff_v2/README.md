# puff_v2 — 물리 v2 · 3D 제트 스파이크 엔진 (설계서 백로그 #1)

설계서: [`docs/design/v2-physics-gameplay.md`](../../docs/design/v2-physics-gameplay.md) §4(물리 v2 사양), §7.2(3D 스파이크), §7.3(엔진 게이트).
범위는 §7.2 '구성' 그대로다. 정직 접촉 원기둥 더미 + BreathProgram + 준정상 원형 제트 + F1·F3·F4(벽 압력 법칙 + 틈 공동) + F6(비행 항력) + 책상 가림 광선 + 제트 동안 480 Hz 공력 + 감사 H1~H4 기록. 벽면 제트·UI 는 없다.

## 🧭 핵심 가설

- **(확인됨) S0 = A0.8 통과.** 벽 압력 법칙 Π_wall = Cp₀·Π_c(x)·c²·exp(−ln2·(r/r½)²)를 제트 폭 3배 판에 적분했다.
  - 수직: 0.998~0.999·J, 45°: 0.687~0.697·J (법칙 경로, 4096점, x 1~9 u, 입 1.1·2.5 cm²).
  - 엔진 F3 경로(실제 딱지 아래 면, 128점, 가림 광선 포함): 0.998·J / 0.704~0.706·J.
  - → 법칙 버그 없음. 진행한다.
- **(확인됨) G1 통과.** 정직 접촉(300 Hz·ζ 10·1440 Hz 서브스텝·μ 0.45/0.38, 딱지별 두께)으로 N 1~80, 20시드를 쟀다.
  - 꼭대기/명목: 64장 ≥ 98.4%, 80장 ≥ 98.0%. 맨 아래 여유 +0.002 u. 3 s 뒤 최대 점 속력 ≤ 0.033 u/s. 무너짐 0.
  - 단, 솔버 반복을 pgs 2·stab 2 로 올려야 했다. 1·1 이면 64장에서 0.11 u/s 떨림이 남아 속력 기준에 걸린다. 아래 '설계서와 다른 점' 참고.
- **(정식 측정 + 감사 반영 1차로 확인됨, [`docs/research/v2-spike.md`](../../docs/research/v2-spike.md))** S0·S1(N 30~40)·S2(F2 없음 조건부)·S4 통과, S3·S6 실패(→ 쓸기 UI 제외, P = 30), S5 판정 불가(kmax 식 없음). 턱 최대 퍽 오라클 평균 20장 0.00·30장 0.03·40장 0.72장.
  - **가설 수정 (감사 반영)**: 턱·눈높이를 해부 범위로 자르자 턱은 약 37장 위를 노릴 수 없고 60장은 0장이다. 쓸기는 9°/s ÷ 고정 1.03 [0.89, 1.19](512짝, 쓸 여유 0~8°). F2 흡입(`f2=2`)을 켜면 30장 퍽이 0.03 → 3.1장, S2 가 뒤집히지만 H1 을 41% 샷에서 어긴다.
- **(정직 엔진 안 확인됨 · 실물 미검증, 2026-10-15, [`docs/research/v2-flatfloor.md`](../../docs/research/v2-flatfloor.md)) 평평한 바닥 숨(입 12.5 mm·10 cm, opt-in `pose=flat`)은 20~45장을 거의 넘기지 못한다.** 게임 문법 고정 숨 3,840샷 전부 0장, 사전 등록 튕김 한 숨 0.00~0.04장, 꼭대기 뒤 0.1 s 버티기 40·45장 0.19장(최선 고정 대비 +0.19 [0.08, 0.29]·[0.04, 0.38]장 — 0 보다 크지만 판 설계에 쓸 수 없는 크기), 30장 이상은 위 절반이 5°도 기울지 않는다(두께·Cp_in·μ ±30%·F2 에서도 같음) → core-sweep §9 1번: 문자 판정 비 ∞(분모 0 → 판가름 불능), 해석 판정 실패.
- **(스모크 신호, 미검증: 시드 2개) 턱 자세는 거의 넘기지 못한다.** 가짜 힘은 넣지 않았다.
  - 1~30장: 사실상 0장이다.
  - 30~50장: 꼭대기 근처 조준(높이 0.75~0.9)에서만 푸어억 평균 0.4~1.6장이다. 원 밖으로 날아가는 것이 3~5장이다.
  - 리서치 추정(20장 3~8, 40장 6~12)보다 한 자릿수 작다.
  - 원인 1: 사양의 틈 식 g = g_rb + δ_i + (a_s − δ_s) + g₀ 때문에 대부분의 경계면이 '둘레가 다 열린 틈'이 된다. 열린 넓이 50~90%, 열린 영역 중심이 딱지 중심 근처(지렛대 ≈ 0)다.
  - 원인 2: 공동 압력이 균일(Π_c·A_open)이라 덩어리가 통째로 1~2 mm 들썩였다가 내려앉는다. 기울지 않는다(최대 약 3°).
  - 원인 3: 턱 제트는 25~31° 내려 분다. 그래서 F3(밑면 직격)는 딱지가 그 각보다 더 기울어야 켜진다.
  - 원인 4: 공중에 뜨면 F1~F4 가 꺼진다(사양). 대신 F6 상대 바람이 들어오는데, 내려 부는 바람이라 딱지를 다시 누른다.
  - 입 쪽으로 말린 한 장(A0.3b 쐐기 Π_c/Π_ext 0.60)도 33°까지 들렸다가 내려앉았다(`trace=1`).
  - **책상 밑**은 밑면을 직접 맞혀 통째 포물선이 나온다. o 0.30~0.45, N 4~8 에서 P(통째) 0.06~0.17, 정점 0.8~1.3 u 다.
  - U1(s·0.89 > 높이 → 0장)도 성립한다.
  - → S1~S3·S6 정식 측정에서 '턱 = 0장 근처'가 확정되면, §7.1 규칙대로 범위 안 손잡이(휨 비율·σ_s·Cp_in) → 기획 목표 → 실물(R2 휨, R3 촬영) 순으로 본다.
  - 사양 밖의 빠진 물리 후보(미검증): ① 공동 압력의 입구→안쪽 기울기(균일 Π_c 가 지렛대를 지운다) ② 벽면 제트(아래 조준이 책상에서 잃는 운동량) ③ F2 윗면 누름(이건 오히려 덜 넘긴다).
- **(확인됨) 감사는 기록만 한다.** 스파이크 스모크 1,430샷 중 위반 샷은 14개(0.98%)다.
  - H2 9샷(외부형 일 / 가로챈 운동에너지 최대 4.2): 추정 원인(1샷 확인)은 제트 가장자리에서 미끄러지는 딱지다. 벽 법칙의 압력 모양(∝ g)이 운동에너지 플럭스(∝ g³)보다 넓은데, 상대 속도 보정이 없다.
  - H2c 4샷: 준정상 공동 Σ Q = 0 이 들림에 따른 부피 증가를 빼지 않는다. 공동 일이 들어온 압력 일의 최대 2.0배다(예산이 바닥값 아래인 경계면 2샷 포함).
  - H1 1샷: 경계 사례(1.03).
  - H3·H4 는 0 이다.
  - 셋 다 사양의 '가짜 힘' 신호이므로 엔진 코어(#2)에서 볼 항목이다. 클램프하지 않았다.
  - 예외는 NaN 이다. 힘이 NaN 이면 월드를 지키려고 그 갱신의 힘을 0 으로 두고 H4 로 센다(지금까지 0건).

## 명령

빌드 캐시는 기존 `native/puff_sim/target` 을 같이 쓴다(선택).

```bash

cargo test --release --offline                      # 23개: 단위(S 3.21)·벽 법칙 적분·S0·H3·H4·결정성·휨 비율·해부 범위·평평한 바닥 opt-in(옛 키 해시 고정)
cargo build --release --offline
B=$CARGO_TARGET_DIR/release/puff_v2

$B settle                                   # G1: N 1,10,20,40,64,80 × 20시드, 3스레드 (약 3 s)
$B settle 40,64,80 20 3 1920                # 대비책 400 Hz × 16 으로
PGS_STAB=1,1 $B settle 64 20                # 솔버 반복 1·1 (떨림 재현)
$B unit                                     # S0 = A0.8 (실패면 종료 코드 2) + A0.7·H3·F1 옆면·말림 쐐기 기록
$B shot n=40 seed=3 pose=chin breath=puff q=1 h=1.2         # 샷 하나 → JSON 한 줄
$B shot n=8 pose=under inset=-0.3 h=0.2 trace=1 2>trace.jsonl   # 스텝 기록(t, j, F1z, F3, F4y, Π_c/Π_ext, vmax, rise, tilt, air)
printf 'n=20 seed=1 h=0.5\nn=20 seed=1 h=0.5 breath=pueok dur=1.93\n' | $B batch 3   # 여러 샷(입력 순서대로)
$B spike S1 seeds=32 threads=3 out=out/S1.jsonl    # 게이트 한 개 (요약 JSON 은 stdout, 샷은 out)
$B probe n=10 seed=2 h=0.4                  # 최대 유량 순간 공력 한 번: 경계면별 g_k·Π_ext·Π_c·열린 넓이·지렛대 (원시 입력 0.15 s, pose=flat 은 build_flat 0.30 s)
```

### 평평한 바닥 고개 쓸기 (opt-in 측정, 2026-10-15)

설계서 [`docs/design/core-sweep.md`](../../docs/design/core-sweep.md) §2.1 기하·§2.3 `rel` 숨을 정직 엔진에 옮겼다. 결과·판정은 [`docs/research/v2-flatfloor.md`](../../docs/research/v2-flatfloor.md).
`pose=flat` 일 때만 켜진다. 옛 자세(턱·눈높이·책상 밑)·옛 키의 샷은 해시·JSON 이 바이트까지 그대로다(바꾸기 전 바이너리로 12샷 대조, `flat_scenario_is_opt_in` 시험).
- 원시 입력 계약 밖이다: `RawInput::from_bytes` 는 자세 코드 3(평평한 바닥)을 받지 않는다(PvP 기록·원시 입력 길로 재지 않은 Flat 숨이 만들어지지 않게). 샷은 `build_flat` 길로만 돈다.
- 잘못 섞은 키는 오류다(조용히 무시하지 않음): 평평한 바닥 키(`rel relx off w t0 a ax area tilt`) + 다른 자세, `pose=flat` + 원시 숨 키(`breath dur sweep delay smax`), `w>0` 인데 `a` 없음, `a=top` 없이 `ax`, `rel=top` 없이 `relx`.

- 기하: 입 (lat, 0.5 u, z_f + 4 u) = 책상 위 12.5 mm·앞면에서 10 cm, 수평 제트에서 시작. 목 축 N = 입 + (0, 1.6, 3.6). 고개 α 만큼 N 둘레로 젖힌다(입이 오르고 제트가 함께 꺾임, α ∈ [0, 45°]).
- 숨(`rel`): 0.26 s 올림 코사인 → 엄지를 뗄 때(D)까지 가득 → 뗀 뒤 `off`(0.04 s) 동안 잦아듦. 유량 3.9 L/s·q, 입 면적 = 푸어억 시간표(`area=puff` 면 1.1 cm² 고정). 원시 입력(30 Hz)을 거치지 않는 연속 시각 측정 프로그램이다.
- 고개: α(t) = 0 (t ≤ t0), 그 뒤 w °/s 로 A 까지(v1 `alphaOf` 그대로, 목 속도 상한 없음). `a=top` 이면 A = 그 더미의 꼭대기 각(바람 자국이 가라앉힌 꼭대기에 닿는 각, 그 `mode` 의 기하로 푼다: (c) 목 축, (a)(b) 0.5 + 4·tan α) + `ax`(0.5°). `rel=top` 이면 D = 도달 + `relx`(0.04 s).
- 기록(`flat` 객체): 꼭대기·꼭대기 각·A·D, 위 절반 평균 기울기가 5°·10°·20° 를 넘은 시각(t5·t10·t20), 0.05~0.4 s 의 위 절반 기울기, 맨 아래 딱지 5°(t_lift), 바람 축이 꼭대기를 넘은 시각과 그때 위 절반 기울기, 70% 통째. `tilt=1` 이면 1/60 s 시계열.
- 민감도 손잡이(게임 손잡이 아님): `tk`(콜라이더 두께 배율, 휨 틈은 그대로), `mk`(질량 배율). 기본 1 이면 더미 열쇠·배치가 옛것과 같다.

```bash
B=$CARGO_TARGET_DIR/release/puff_v2
$B shot n=40 seed=401 pose=flat q=0.85 rel=0.8 tilt=1                        # 고정 숨 0.8 s 에 떼기
$B shot n=40 seed=401 pose=flat q=0.85 w=120 t0=0.3 a=top rel=top            # 사전 등록 튕김(꼭대기 각 + 0.5° 에서 떼기)
$B shot n=45 seed=401 pose=flat q=0.85 rel=0.6 tk=2.1 mk=2.1 cp_in=0.56       # 두께 ×2.1·들기 ×0.7
$B probe n=40 seed=401 pose=flat                                            # build_flat 길, 0.30 s 순간(최대 유량 j 14.3) 경계면별 공력. q=0.6 이면 j 5.15. PROBE_T=초 로 시각 바꿈
cd scripts && THREADS=2 node flatfloor.mjs run base401 base601 sens f2 nscan aimtop && node flatfloor.mjs v1 2 && node flatfloor.mjs v1check && node flatfloor.mjs report
```

### 샷 API (다음 단계용)

Rust:

```rust
let spec = ShotSpec::new(n, seed, Pose::Chin, BreathSpec::pueok(1.0, 1.93).with_sweep(9.0, 0.3), lat, h);
let r: ShotResult = puff_v2::run_shot(&spec);        // 또는 run_batch(&specs, 3)
r.flipped; r.out; r.zero; r.audit.h1 /* … */; r.to_json();
```

CLI 키는 `n seed pose=chin|eye|under|flat breath=puff|pueok q dur sweep(°/s) delay smax mode=c|a|b h lat inset sigma warp cp0 cp_in cd f2=0|1|2 cs edge=0|1 audit trace max_after mu_pp mu_pt pgs stab solver=1440|1920 fwarp=curl:0.03:90 ftop tag` 이다.
- 평평한 바닥(`pose=flat`)만: `rel=D|top relx off w t0 a=도|top ax area=pueok|puff tilt=1`, 더미: `tk mk`.
- `f2=1` 윗면 충돌만(옛 선택), `f2=2` 충돌 + 스치는 흐름 흡입(§4.7 F2 전체, `cs` 기본 0.8). 기본 0 = §7.2 스파이크 구성.

## 힘·감사 구현 세부 (사양이 정하지 않은 것)

**F1 옆면**
- 딱지 테두리 24칸의 칸 중심(R + ε)에서 벽 법칙을 쓰고, 입에서 보이는지 광선으로 판정한다.
- 넓이는 호 × 콜라이더 두께다.

**F3 노출 밑면**
- 아래를 향한 면에 해바라기 128점을 쓴다. 넓이는 πR²/128 씩이다.
- 받침과 접촉 중인 경계면 영역(받침 원판 발자국 안, 받침이 책상이면 책상 위)은 F4 몫이라 F3 에서 뺀다.
- 그 밖의 점은 아래 틈 > 0.004 u 이고 보일 때만 센다. F3 와 F4 가 같은 면을 두 번 세지 않는다.

**F4 틈 공동**
- 경계면은 (딱지, 받침)이 rapier 활성 접촉일 때만 있다.
  - 받침은 아래쪽 짝 중 수평으로 가장 가까운 것, 없으면 책상이다.
  - 거의 선 딱지(up.y < 0.5)에는 공동이 없다.
- 노드 틈 g_k 는 사양 식 그대로다.
  - g_rb 는 받침 윗면 평면까지의 거리다. 받침 축에서 R + 0.15 넘게 벗어나거나 책상 밖이면 g_cap 0.25 u(활짝 열림)다.
- 휨 방향: 휨은 로컬 −y 쪽(처음 그림-아래 자세에서 세계 위)이다. 뒤집힌 딱지는 bottom_offset 과 top_empty 가 서로 바뀐다.
- 입구 점은 가상 틈의 가운데다(받침 면보다 최소 1e-4 위). 두 장 자신은 가리개에서 뺀다(가상 기하, §4.3). 책상은 가린다.
- 통로는 L = R/2, 대표 틈 = h(0.75R)(Poiseuille), Cd 0.6 이다.
- 열린 영역은 h(r,φ) > 0.004 인 경계면 안 표본이다. 힘은 그 중심에 걸고 받침에는 반대 힘을 건다.

**F6 비행 항력**
- 정지 공기(접촉 중이거나 제트 없음)는 사양 식 그대로다(중심 v, e_cp, C_ω).
- 제트 원뿔 안의 공중 딱지는 같은 식을 면 128점에서 국소 상대 속도 v + ω×r − u_air(P) 로 적분한다.
  - u_air 는 입에서 그 점까지 가리면 0 이다.
  - ω×r 이 들어가므로 C_ω 항은 따로 더하지 않는다(C_ω 는 이 적분의 유도값 8/15π·Cd_n).
  - e_cp 는 평균 흐름으로만 더한다.

**감사 묶음**
- 벽 압력 모양(∝ e^{−ln2 η²})에서 무게가 같은 12고리 × 24부채꼴 광선(합 = J)을 쏜다.
  - 경로는 코어 안 평행, 코어 뒤 η·c_s 로 퍼진다.
- 첫 충돌 딱지가 J 몫과 운동에너지 몫(J 몫 × Uc·e^{−2ln2 η²})을 가로챈다.
- H1: 덩어리(딱지-딱지 접촉 연결 성분)마다 |Σ(F1+F3+제트 몫 F6)| ≤ 1.3·J_int + 0.02·J + 0.01·W_ref 를 본다. 공동은 경계면마다 Π_c ≤ max Π_ext 를 본다.
- H2: 숨 하나 동안 딱지마다 외부형 일 ≤ 0.6·가로챈 운동에너지 + 0.01·W_ref·u 를 본다.
- H2c: 경계면마다 공동 일(위 장 + 받침) ≤ 들어오는 흐름의 압력 일 Σ Q⁺·p_ext + 0.01·W_ref·u 를 본다.
- H3: 정지 딱지·정지 공기에서 F6 ≠ 0 이면 위반이다.
- H4: NaN 수, 공력 모듈 소스에 난수 흔적이 있는지(시험)를 본다.

**판정**
- 제트 뒤에 max(\|v\|, \|ω\|R) < 0.05 u/s 가 0.25 s 이어지면 멈춘다(최대 6 s).
- 뒤집힘 = 그림 면(로컬 +y)·세계 y > 0.2 이고 원 안이다.

## 설계서와 다른 점·생략 (이유)

1. **솔버 반복 pgs 2·stab 2** (사양 표에 없음). 1·1 이면 64·80장에 3 s 뒤 0.11 u/s 떨림이 남아 G1 속력 기준에 걸린다. 물리 손잡이가 아니라 수렴 정밀도다. 같은 접촉 Hz·ζ·서브스텝에서 높이는 같다.
2. **contact_recycling 끔.** rapier 기본 재활용 거리 0.05 u 가 딱지 두께와 같아 접촉이 낡는다. gyroscopic 은 켰다(물리).
3. **F3 면 표본 128점** (사양: 밑면 7 + 안쪽 고리 12 = 19점). 19점으로는 r½ ≈ 0.3 가우스를 R = 1 면에서 약 0.4·J 로 적분해 S0 가 깨진다.
4. **F6 공중·제트는 면 적분 + 가림.** 사양 식에 중심 바람을 원판 전체에 쓰면 원판이 제트보다 넓어 힘이 J 의 여러 배가 된다(H1 3.1×·H2 위반으로 확인). 같은 식을 국소로 적분하고, D9 가림을 바람에도 적용했다.
5. **H2 를 둘로 나눔(H2 + H2c), H1 에 제트 몫 F6 포함, 묶음 양자화 여유.**
   - 공동이 하는 일은 딱지 자신의 투영 면적이 아니라 틈 입구로 들어온다. 사양 그대로면 속 딱지가 늘 위반이다.
   - 여유(0.02·J + 0.01·W_ref)는 288광선 묶음의 꼬리 해상도 때문이다.
6. **F2 윗면은 선택, 기본 끔.** §7.2 스파이크 구성(F1·F3·F4)을 따랐다. `f2=2` 가 §4.7 F2 전체(충돌 + 흡입: |d·n| < 0.26 이고 유동 앞 1/3 인 덮이지 않은 윗면 점에 Π = −Cs·Π_loc·(1 − |d·n|/0.26), 가림 광선은 자기 자신 제외)다. 흡입은 제트가 딱지를 맞히지 않고 스쳐도 힘을 내므로 H1(가로챈 J 기준)에 걸릴 수 있다(사양 자체의 긴장, 기록).

   - **책상 받침의 책상 밖 노드 (감사 반영, 2026-10-13)**: 노드의 반지름 선이 책상 모서리를 지나는 점 E 를 입구로 둔다. Π_ext = Cp_in·Π_wall(E 바로 밖, 밑면 법선), 틈 = E 에서 책상까지 + 휨·(r_E/R)² + g₀, 열린 넓이 보간용 테두리 틈 = g₀ + (g_E − g₀)/λ². 밑면 중심이 책상 밖이면 닫힌 노드. 옛 선택(테두리 R+ε 에서 반지름 법선, 틈 0.25)은 공동 입구가 아닌 곳의 정체압을 공동에 넣었다. `edge=0` 으로 되돌릴 수 있다.
